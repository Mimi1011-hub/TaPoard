TaPoard 4.0 更新案内
===================

4.0で追加・変更した内容
-----------------------

・設定を、通知領域の「設定を開く」から表示する設定ウインドウへまとめました。ボタンや部品の追加・並べかえは PC で行います。
・スマートフォンは、配置済みのボタンや部品を押すだけの画面になりました。
・日本語と英語を用意しました。インストールのときに選べて、あとから「全般」で自動・日本語・English を切り替えられます。
・ショートカット一覧を4分類に整理し、VS Code の操作を追加しました。
・ショートカットパック（.tpshortcuts）と、画面のプリセット（.tppreset）を読み込み・書き出しできるようになりました。
・ページを左右にスワイプして切り替えられます（PC ウインドウでも同じです）。
・「再生中の曲」の部品を追加しました。PC で再生中の曲名・アルバムの絵・進み具合を表示し、前へ・再生/停止・次へを操作できます。
・「カレンダー」の部品を追加しました。1×1（今日）、2×1（今週）、3×3（今月）で、今日に丸が付きます。
  日本語のときは日本の祝日も赤で出ます（英語のときは祝日を出しません）。週の始まりは日曜・月曜から選べます。
・インストールが終わると、設定の「接続」が開き、QR コードをそのまま読み取れるようになりました。

3.1 からの入れかえ方
--------------------

TaPoard 3.1 が入っている PC では、このインストーラーをそのまま上から実行してください。
登録したボタン、接続、見た目などの設定は、最初の起動時に引き継がれます。

3.1 に戻す場合は、TaPoard 3.1 のインストーラーをもう一度実行してください。

再生中の曲について
------------------

Windows 10（1809 以降）と Windows 11 で使えます。Spotify やブラウザなど、Windows のメディア操作に対応したアプリの曲を表示します。

まだ無いもの
------------

マクロは、このあとの版で追加する予定です。ダークとライトの切り替えのうち、ライトはまだ使えません。
