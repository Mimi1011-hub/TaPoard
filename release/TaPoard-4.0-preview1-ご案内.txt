TaPoard 4.0 preview 1 ご案内
================================

この版について
--------------

これは TaPoard 4.0 を触って確かめるためのプレビュー版です。
使いにくい所、分かりにくい所、正しく動かない所など、気づいた点を教えてください。

4.0 で変わったこと
------------------

・設定を、通知領域の「設定を開く」から表示する設定ウインドウへまとめました。
・スマートフォンは、配置済みのボタンや部品を押すだけの画面になりました。追加や並べかえは PC で行います。
・ショートカット一覧を4分類に整理し、VS Code の操作を追加しました。
・ショートカットパック（.tpshortcuts）を読み込めるようになりました。
・日本語と英語を用意しました。インストールのときに選べて、あとから「全般」で自動・日本語・English を切り替えられます。

3.1 からの入れかえ方
--------------------

TaPoard 3.1 が入っている PC では、このインストーラーをそのまま上から実行してください。
登録したボタン、接続、見た目などの設定は、最初の起動時に引き継がれます。

3.1 に戻す場合は、TaPoard 3.1 のインストーラーをもう一度実行してください。

まだ無いもの
------------

マクロと、再生中の曲を表示する機能は、このあとの版で追加する予定です。
