プリセットタブでプリセットを選ぶと、下に「ボタンの説明」の一覧が出る（`web/v4/settings/presets.js` の `help()`）。
用意されたプリセットはアイコン・名前・説明・送るキーが出るが、自分のプリセットはアイコンが出ないものが多く、説明も無い（Hiro の画面で確認）。

## 1. 不具合: 自分のプリセットの説明の一覧でアイコンが出ない

原因: `help()` は `item.icon` を用意されたプリセットのアイコンの名前として `presetIconNode(item.icon)` で描き、無いときは `widgetMarks`（時計・天気・PC 情報だけ）を使う。
自分のプリセットのボタンは盤面のボタンそのもの（`DeckItem`）なので、アイコンは `iconKey`・`customIcon`・`iconPack` / `iconPackItem`・アプリのアイコンなどで持っていて、
`icon` が空なら何も出ず（マイク、スピーカー、デスクトップなど）、`icon` がアプリのアイコンなどプリセットの名前でない値なら「?」になる（ChatGPT、Claude など）。

直し方:
- 自分のプリセットのボタンは、盤面と同じ描き方（`web/v4/deck/icons.js` の `iconNode(item)`。設定の詳細欄 `inspector.js` と同じ）でアイコンを出す。
  部品（時計・天気・PC 情報・ホイール・タッチパッド・テンキー・スライドショーなど）は、カタログと同じ部品のアイコン（`widgetGlyphNode` など）を出す。
- 用意されたプリセットの見え方は変えない。
- 指示書 24 で読み込んだプリセット（自分の画像のアイコンを外したもの）も、標準のアイコンで出ること。
- UI テスト: 自分のプリセットに、標準のアイコン・アプリの起動・アイコンパックのアイコン・時計・ホイール・テンキーを入れ、説明の一覧のすべての行にアイコンが出て、「?」や空の行が無いこと。
  テスト用のプリセットは本物の `CustomPresets.Public()` と同じ形にする。

## 2. 自分のプリセットのボタンにも説明を出す

用意されたプリセットと同じく、各ボタンの名前の下に「何をするボタンか」と「送るキー」を出す。

- 説明の文は、そのボタンの種類から作る（日本語・英語）。例:
  - ショートカット（カタログにあるもの）: カタログの項目の名前と説明（例「画面切り取り」「Win + Shift + S」）。送るキーの行に「送るキー：Win + Shift + S」。
  - キーを変えたもの・自由なキー: 「送るキー：Ctrl + Alt + P」。
  - アプリを起動: 「アプリを起動します：<ファイル名>」（フルパスではなくファイル名だけ）。
  - URL を開く: 「ブラウザで開きます：<URL のホスト名>」。
  - 文字を入力: 「文字を入力します」と、入力する文字の最初の 20 文字ほど。
  - 音量・ミュートなど PC が直接するもの: 用意されたプリセットと同じ「キーは送らず、TaPoard が直接操作します」。
  - 部品: 部品の名前とカタログの説明（例「デジタル時計」）。指示書 23 のスワイプが効かない一文も、カタログと同じく出す。
  - 音の出力・入力先を変えるボタン: 「音の出力先を切り替えます：<装置の名前>」（名前が無ければ「既定の装置」）。
- 文を作る処理は1つのファイル（例: `web/v4/settings/item-help.js`）にまとめ、カタログのデータ（`catalog-data/`）と辞書を使う。カタログと別に文を書き写さない。
- フェーダーの行（スピーカー・マイク）は今のまま。
- テスト（node）: 種類ごとの説明の文（日本語・英語）。UI テスト: 自分のプリセットを選ぶと、各行に説明が出る。1100px の日本語・英語で切れない。
