# 依頼書 4.0-16：古い画面と古い API を消して、4.0 プレビュー版を作る

TaPoard 4.0 作り直しの最後の回です。新しい画面（`web\v4\`）と設定ウインドウがそろったので、**古い画面と、古い画面だけが使っていた API を消し**、説明書を 4.0 に合わせ、**触って確かめるためのプレビュー版のインストーラー**を作ります。新しい機能は足しません。

| 回 | 内容 |
|---|---|
| 14 | ショートカット一覧の4分類・VS Code・ショートカットパック（済み） |
| 15 | 英語をすべて・トレイとインストーラーの文言（**済み。`develop/4.0` にマージ済み**） |
| **16** | **古い画面と古い API の削除、説明書、4.0 プレビュー版**（この依頼） |

「メモリ上の設定も v3 の形にする」は今回やりません（プレビュー版を触ってから決めます）。

## 0. 最初に知っておくこと（15 のレビューで直した所）

`develop/4.0` の先頭が `Wrap lines longer than 160 characters` なら最新です。15 のあと、次の所を直しました。同じことを今回もしないでください。

- **英語は機械翻訳を使わない。** 15 の `TextEn.cs` は機械翻訳のままで、「取り消し → cancel」「保存 → keep」「は → teeth」のような誤訳が多く、全部書き直しました。英語は文の意味を読んで自分で書くこと。迷ったら日本語の意味を1行そえて報告に書く。
- **文をつなげて作らない。** `label + Text.Get("…")` のように日本語の語順で切った断片をつなぐと、英語にならない。数や名前が入る文は `Text.Get("キー", 値)` と `{0}` で1つの文にする（もう直してあります。今のコードが手本）。
- **日本語の文を勝手に変えない。** インストーラーの日本語が短く書きかえられ、「スマートフォン」が「phone」になっていたので元に戻しました。
- **見た目の文字ではないものを辞書に入れない。** 天気の地名の「市・都・府・県」や「アンインストール」は照らし合わせに使うデータなので、`"\u5e02"` のように書いてコードに戻しました。
- **起動時に1回だけ作る表に `Text.Get` を入れない。** `DeckPresets` と `WidgetRegistry` は言語を切り替えても古い言語のままだったので、言語が変わったら作り直す形にしました。
- テストは Windows が英語でも通ること。日本語の文を見るテストは最初に `Text.Use("ja")` を呼ぶ。
- 英語で決めた言い方：部品 = `widget`、枠 = `grid`（空き枠は `empty space`）、保存した見た目 = `look`、PC情報 = `PC info`、テンキー = `keypad`、全画面 = `full screen`、スマホ = `phone`。
- 160 文字をこえる行は全部折り返しました（辞書の文・アイコンの絵のデータ・URL は対象外）。`settings\editor-state.js` の配置の確認は `settings\deck-rules.js` に分けました。今回も1行 160 文字まで、JS は1ファイル 300 行まで。

## 1. 作業の始め方（1つのチャットで通して行う）

1. `develop/4.0` を最新にして、`gpt/4.0-16-remove-old-preview` を切る。
2. 3.1 → 3.7 の順に作る。1項目ごとに commit する。途中で止まって報告しなくてよい。
3. 作業中はその項目に関係するテストだけ。全部のテストは最後に1回。
4. 終わったらブランチのまま止める（マージと push はレビュー後に Claude が行う）。
5. 使用量が足りなくなりそうなら、項目の切れ目で commit して、どこまで終わったかを1行で報告して止める。

チャットの最初に貼る文：

- **消す前に必ず検索する。** API・関数・ファイルを消すときは、`web\v4\`・`src\`・`installer\`・`packaging\`・`tests\v4-*`・`tests\*.mjs` から使われていないことを `rg` で確かめてから消す。1か所でも使われていたら消さずに報告に書く。
- **新しい画面と、スマホからの動きを変えない。** `/api/v3/*` と、3.3 の表にない API はそのまま。
- **設定ファイルの形を変えない。** `settings-v3.json`、3.1 からの移行、バックアップはそのまま。メモリ上の `Settings` クラスもそのまま。
- 画面に出る文字は C# は `Text.Get`、Web は `i18n`。日本語と英語を必ず両方書く。日本語の今の文は変えない。

- 個人が分かる文字（名前・メール・`C:\Users\<名前>` の道）を入れない。

## 3. やること

### 3.1 古い画面を消す

- 消すファイル：`web\app.js`、`web\index.html`、`web\pc-window.html`、`web\pc-window.js`、`web\style.css`。
- 残すファイル：`web\qrcode.js`、`web\nosleep.min.js`、2つのライセンス文、`web\manifest.webmanifest`、`web\icon-*.png`、`web\v4\` の全部。
- `Program.Http.cs`：
  - `PublicFiles` から消したファイルと `/settings`・`/pc-window` を外す。
  - **`/` は `/v4/` へ送る**（`302`、`Location: /v4/`）。スマホの QR の URL（`http://…/#connect=…`）とホーム画面に置いた古いアイコンがそのまま使えるようにするため。`#` より後ろはブラウザーが引きつぐので、サーバーでは何もしない。
  - `/settings` と `/pc-window` は 404 でよい。
- `web\v4\index.html` に `manifest` と `apple-touch-icon` のリンクが無ければ足す（古い `index.html` と同じもの）。`manifest.webmanifest` の `start_url`・`scope`・`id` は `/` のまま。
- **WebView2 が無い PC**：今は `OpenLegacySettings()` で古い設定画面をブラウザーで開いている。これを `http://127.0.0.1:<port>/v4/settings.html#admin=…` をブラウザーで開く形に変える（関数名も `OpenSettingsInBrowser` にする）。

### 3.2 トレイと PC 用ウィンドウのメニューを整える

- トレイの「古い設定画面をブラウザで開く」を消す（辞書の `source.program.5` も消す）。
- トレイの「PC 用ウィンドウの設定」と、PC 用ウィンドウのボタン「PC 用ウィンドウの設定（Ctrl+,）」は、古い `/pc-window` のページを開いていた。これを **設定ウインドウを開いて「PC画面」を出す**ように変える。
  - 設定ウインドウの URL に `&section=pc` を足して開く（例：`…/v4/settings.html#admin=…&section=pc`）。`settings-app.js` で読み、`shell.chooseSection('pc')` を呼ぶ。知らない名前は無視する。
  - 設定ウインドウがもう開いているときは、手前に出して「PC画面」に切り替える（`SettingsWindow` に URL を開き直すか、ページへ知らせる小さな関数を足す。どちらでもよいが、開き直す場合は保存中の変更が消えないことを確かめる）。
- `source.pcwindow.6`（WebView2 が無いときの案内）は「通知領域の TaPoard から『設定を開く』を選ぶと、ブラウザで操作できます。」に直す。英語は `\n\nTo use a browser instead, choose "Open settings" from the TaPoard menu in the notification area.`。**これは今回、日本語を変えてよい唯一の文です。**

### 3.3 古い API を消す

新しい画面が使っていない API は次の7つです（2026-11-16 に `web\v4\` を検索した結果）。もう一度自分で検索して確かめてから消す。

| 消す API | 代わり |
|---|---|
| `GET /api/state` | `GET /api/v3/state` |
| `GET /api/settings`、`POST /api/settings` | `GET/POST /api/v3/deck` |
| `POST /api/layout` | `POST /api/v3/deck` |
| `POST /api/fader/remove` | `POST /api/v3/deck` |
| `POST /api/page/delete`、`POST /api/page/move` | `POST /api/v3/deck` |

- `POST /api/page/undo` と `POST /api/page` は新しい画面が使っているので**残す**。
- それぞれのコントローラーから登録と処理の関数を消す。その関数だけが使っていた下請けの関数も消す（`rg` で他から使われていないことを確かめる）。`/api/v3/deck` やプリセット・保存した見た目が使っている関数は消さない。
- `ApiRouteTableTests` の一覧と数を合わせる。消した API を呼んでいた C# のテストは、同じことを `/api/v3/*` で確かめているなら消し、確かめていないなら v3 の呼び方に書きかえる。
- 使わなくなった辞書のキーを `TextJa.cs` と `TextEn.cs` の両方から消す。

### 3.4 古い画面のテストを消す

- 古い画面を開いている UI テスト（`tests\` の `*-ui.cjs` のうち `v4-` で始まらないもの。`audio-ui`、`background-ui`、`clock-ui`、`fader-pages-ui`、`icon-pack-ui`、`icon-style-ui`、`import-url-ui`、`integration-ui`、`keypad-ui`、`metrics-ui`、`page-delete-ui`、`preset-ui`、`release103-ui`、`slideshow-ui`、`touchpad-ui`、`weather-ui`、`wheel-ui`）を消す。
- 消す前に、各テストの最後の `PASS …` の行を読み、**同じ内容が `v4-*-ui.cjs` にあるか**を見る。新しい画面に同じ確かめが無いものは、消さずに一覧にして報告に書く（今回は書き足さない）。
- `tests\run-unit.ps1`・`tests\playwright.cjs`・`doc\gpt\4.0-00-working-rules.md` に古いテストの名前が残っていたら直す。
- `tests\fixtures\` のうち、消したテストだけが使っていたものを消す。

### 3.5 小さな直し

- 時計の日付：英語のとき `2026/11/16 Monday` と出る。英語では `Mon, Nov 16, 2026` の形にする（`toLocaleDateString('en-US', …)` は使わず、月と曜日の短い名前を辞書に足して組み立てる。日本語の出方は変えない）。曜日だけ・日付だけの設定でもおかしくならないこと。`v4-widgets-ui.cjs` に英語の確かめを1つ足す。
- 設定ウインドウの「接続」の説明など、文の中に「ブラウザ」「古い設定画面」と書いている所が残っていないか `rg` で探し、今の作りに合わない文は報告に書く（勝手に書きかえない）。

### 3.6 版の番号と説明書

- 版：`src\BuildInfo.cs` の `ReleaseVersion` を `4.0` に。`installer\Installer.cs` の `3.1+source` を `4.0+source` に。`package.ps1` の `$version` を `4.0-preview1` に（インストーラーは `release\TaPoard-Setup-4.0-preview1.exe`）。`BuildInfoTests` を合わせる。
- `package.ps1` の「入っているか確かめるファイル」の一覧から消したファイルを外し、`web\v4\index.html`、`web\v4\settings.html`、`web\v4\app.js`、`web\v4\i18n\ja.json`、`web\v4\i18n\en.json`、`web\nosleep.min.js` を足す。
- `packaging\README.txt`（日本語）と `packaging\README.en.txt`（英語）を 4.0 の内容に書き直す。見出しは今のまま（初回の接続、使い方、つながらないとき、安全のため、アンインストール）。変わった点：
  - 設定は「通知領域の TaPoard →『設定を開く』」で出る**設定ウインドウ**で行う（ブラウザーの設定画面は無くなった）。
  - スマートフォンは押すだけ。ボタンの追加や並べかえは PC で行う。
  - 左の列：配置・見た目・保存・接続・PC画面・全般。
  - 言語は「全般」で切り替える（自動・日本語・English）。
  - 3.1 の設定は最初の起動で自動で引きつがれる。
- `release\TaPoard-4.0-preview1-ご案内.txt` を新しく作る（`release\TaPoard-3.0-ご案内.txt` と同じ書き方。日本語）。中身：
  - これは確かめ用の版であること。気づいた点を教えてほしいこと。
  - 4.0 で変わったこと（設定ウインドウ、スマホは押すだけ、4分類の一覧と VS Code、ショートカットパック `.tpshortcuts`、英語と言語の切り替え）。
  - 3.1 からの入れかえ方（そのまま上からインストール。設定は引きつがれる。元に戻すときは 3.1 のインストーラーを入れ直す）。
  - まだ無いもの（マクロ、再生中の曲の表示は 4.1 の予定）。
- 個人の名前・メール・PC の名前を書かない。

### 3.7 仕上げとプレビュー版

1. 全部のテストを1回（C#・`*.mjs`・`v4-*-ui.cjs`）。
2. `rg -n "app\.js|pc-window\.html|/api/settings|/api/layout|/api/state\b" src web installer packaging tests package.ps1` で消し残しが無いことを見る（`web\v4\app.js` と `/api/v3/state` は残ってよい）。
3. `package.ps1` を実行して `release\TaPoard-Setup-4.0-preview1.exe` を作る。失敗したら、エラーの最後の10行を報告に書いて止める。
4. 作ったインストーラーと `TaPoard-4.0-preview1-ご案内.txt` の2つだけを `release\TaPoard-Setup-4.0-preview1.zip` にまとめる。**`release\` の中の `.exe`・`.zip`・作業用フォルダーは commit しない**（ご案内の `.txt` だけ commit する）。
