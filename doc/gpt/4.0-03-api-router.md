# 依頼書 4.0-03：API の振り分けを「ルート表」にする

TaPoard 4.0 作り直しの段階2（前半）です。01・02 と同じく **動きは 3.1 とまったく同じ**のまま、`src\Program.Api.cs` の `Route()`（約250行の if / else if の連なり）を、**「メソッド・パス・権限・処理」を1行ずつ並べたルート表**に置き換えます。

処理の中身（設定の変更など）を Controller / Service クラスへ移すのは次の依頼書 04 です。今回は「どの URL がどの処理に行くか」「誰が呼べるか」を表にして、テストで固定するところまでです。

## 1. 必ず守ること（01・02 と同じ）

- **C# 5 で書く**（`$"..."`、`?.`、`nameof`、`=>` メソッド、自動プロパティの初期値、`using static`、`when` は使わない）。ラムダ式 `r => SetPage(r, r.input)` は C# 5 でも使ってよい。ビルドは `v4.0.30319\csc.exe`。
- **外部パッケージを入れない。新しい .cs は `src\` 直下に置く**（サブフォルダーはビルドされない）。
- **動き・API・JSON・設定ファイルを変えない。web\ は触らない。** URL、受け付けるメソッド、権限、返すステータスコード（200 / 400 / 401 / 403 / 404）、返す JSON をすべて今と同じにする。
- **テストがリフレクションで使う名前を残す**：Program のフィールド `config`、`admin`、`lan`、`store`、メソッド `Handle`、`SplitOrientationApps`、`ValidateEntry`、`Launch`、`UseHost`、`UseStore`、`VolumeKey`、`ApplyAudio`、`Save`。

- **個人情報を入れない。** 作者は `TaPoard Developer <353783363+Mimi1011-hub@users.noreply.github.com>`。
- 1つのまとまりごとに小さく commit する（英語1行）。

## 2. 今の Route() の決まり（これを変えないこと）

`Route()` は上から順に次のように動いています。新しい形でも結果が同じになるようにしてください。

1. `POST /api/pair/start` と `GET /api/pair/status` は**キーがなくても**呼べる（ペアリング前の端末用）。`PairStart` は自分で `ReadInput` する。
2. `GET /api/pair/manage` は管理者（設定画面）だけ。
3. それ以外で `r.allowed` が false なら **401** `{"error":"接続キーを確認してください"}`。
4. GET は表にあれば処理、なければ（管理者専用を管理者以外が呼んだ場合も）**404** `{}`。
5. GET でも POST でもなければ **404** `{}`。
6. POST は**先に `ReadInput` と `Json(input)` をしてから**表を探す。なければ（管理者専用を管理者以外が呼んだ場合も）**403** `{}`。
7. 処理の中で例外が出たら、今と同じく `Handle` の catch で **400** `{"error": ...}`。

POST の「`/api/background` で始まるパス」「`/api/icon-styles/` で始まるパス」「`/api/icon-packs/` で始まるパス」は前方一致です。前方一致は**完全一致の表を見たあと**、登録した順に見ます。

## 3. やること

### 3.1 ルート表のクラスを作る（`src\ApiRouter.cs`）

`Program.Request` に依存しないよう、型引数で受け取る作りにします（テストでは `string` などで試せる）。

```csharp
enum ApiAccess
{
    Open,   // キーがなくても呼べる（ペアリング用）
    Paired, // ペアリング済みの端末と設定画面
    Admin,  // この PC の設定画面だけ
}

// 起動時に一度だけ作り、あとは読むだけ。ロックは持たない。
sealed class ApiRouter<T>
{
    internal void Get(string path, ApiAccess access, Action<T> handler);
    internal void Post(string path, ApiAccess access, Action<T> handler);
    internal void PostPrefix(string prefix, ApiAccess access, Action<T> handler);

    // Open のルートだけを完全一致で探す。なければ null。
    internal Action<T> FindOpen(string method, string path);
    // Paired と（isAdmin のときだけ）Admin のルートを探す。完全一致 → 前方一致（登録順）。なければ null。
    internal Action<T> Find(string method, string path, bool isAdmin);
    // テスト用。「GET /api/state Paired」「POST /api/icon-packs/* Admin」の形で、登録順に返す。
    internal List<string> Describe();
}
```

- 同じメソッドとパスを2回登録したら例外にする（書き間違いの防止）。
- `Find` は呼ぶ人が使えないルート（管理者以外から見た Admin）を**ないものとして**扱う。

### 3.2 Request に入力を持たせる（`src\Program.Http.cs`）

- `sealed class Request` を `internal sealed class Request` にする。
- フィールド `internal Dictionary<string, object> input;` と `internal string json;` を足す。POST のとき、表を探す前に `Route()` が入れる。

### 3.3 ルート表を作る（`src\Program.Routes.cs`、新しいファイル）

```csharp
partial class Program
{
    static readonly ApiRouter<Request> api = BuildApi();

    static ApiRouter<Request> BuildApi()
    {
        var api = new ApiRouter<Request>();
        // ペアリング
        api.Post("/api/pair/start", ApiAccess.Open, PairStart);
        ...
        return api;
    }
}
```

- 領域ごとにまとめてコメントを付ける：**ペアリング / 画面の状態と同期 / ページと配置 / ボタンの見た目（背景・アイコンパック・保存した見た目・プリセット・バックアップ） / 入力と操作 / PC ウインドウとファイアウォール / その他（天気・スライドショー・インポート・キー）**。04 で Controller に分けるときの単位になります。
- 今 `Route()` の中に直接書いてある処理（`/api/import` GET、`/api/devices`、`/api/background/image`、`/api/slideshow`、`/api/slideshow/pick-folder`、`/api/view`、`/api/input`、`/api/input/keepalive`・`release`、`/api/settings` POST、`/api/rotate`、`/api/pc-window/open`、`/api/firewall/repair`、`/api/weather/search` など）は、**中身を変えずに名前の付いた static メソッドへ移す**（例：`GetBackgroundImage(Request r)`、`UpdateView(Request r)`、`SendInput(Request r)`）。
- 今 `(Request r, Dictionary<string, object> input)` を受け取るメソッドは、シグネチャを変えずにラムダでつなぐ：`api.Post("/api/page", ApiAccess.Paired, r => SetPage(r, r.input));`
- 前方一致の3つは、今と同じく残りの部分を渡す：`r => IconPackAction(r, r.path.Substring("/api/icon-packs/".Length), r.input, r.json)`。

### 3.4 Route() を短くする（`src\Program.Api.cs`）

`Route()` を「2. 今の決まり」の 1〜6 だけを書いた20行ほどのメソッドにする。

```csharp
static void Route(Request r)
{
    var open = api.FindOpen(r.method, r.path);
    if (open != null) { open(r); return; }
    if (!r.allowed) { 401 }
    if (r.method == "GET") { 表 or 404 }
    if (r.method != "POST") { 404 }
    r.input = ReadInput(...); r.json = Json(r.input);
    表 or 403
}
```

注：`GET /api/pair/manage` は今は 401 チェックより前にありますが、管理者は必ず `allowed` なので、表の `Admin` に入れても結果は同じです。表に入れてください。
