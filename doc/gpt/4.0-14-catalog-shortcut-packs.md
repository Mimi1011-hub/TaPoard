### 3.1 一覧のデータを4分類に組み直す

今の `settings\catalog-data.js` は分類が横一列に 12 個あります。これを **大分類（4つ）→ 分類 → 項目** の3段にします。

| 大分類（id） | 分類（今の `id`） |
|---|---|
| 部品 `parts` | 音量フェーダー（`audio` のうち `control-speaker-fader`・`control-mic-fader`）、情報 `info`、マウス `mouse`、写真 `photo`、キーボード `keyboard` |
| 操作 `actions` | 音量・ミュート（`audio` のうち `audio-*` の6つ）、よく使う操作 `common`（`key-custom` は除く）、Windows `windows`、音楽 `music`、ブラウザ `browser` |

### 3.4 C#：ショートカットパックを PC に保存する

`src\IconStyles.cs` と同じ作りで `src\ShortcutPacks.cs` を足します（`data\shortcut-packs\<id>.json` に1パック1ファイル。`settings-v3.json` には入れない）。

- 中身：`id`（PC が作る。英数字だけ）、`name`（60 文字まで・必須）、`author`（60 文字まで）、`app`（60 文字まで）、`iconPack`（アイコンパックの id か空）、`created`、`shortcuts`（1〜300 個）。
- ショートカット1つ：`name`（80 文字まで・必須）、`keys`（必須。`ShortcutKeys.ParseCombo` を通るものだけ）、`description`（80 文字まで）、`icon`（アイコンパックの中の項目名か空・80 文字まで）。
- 上限：パックは 20 個まで。超えたら分かる文で断る。知らない欄は捨てる。1つでもキーがおかしければ全体を断る（どの名前のキーがだめかを文に入れる）。
- 書き込みは `IconStyles` と同じく一時ファイルから置き換える。`id` は必ず `^[a-z0-9]{8,40}$` を確かめてからファイル名にする（道をさかのぼる文字を通さない）。
- API（すべて `ApiAccess.Admin`。`LookController.cs` に足す）：

| API | 内容 |
|---|---|
| `GET /api/shortcut-packs` | `{ packs: [...中身すべて], maxPacks: 20, maxShortcuts: 300 }` |
| `POST /api/shortcut-packs/save` | `{ name, author, app, iconPack, shortcuts }` → `{ id }` |
| `POST /api/shortcut-packs/delete` | `{ id }` → `{ ok: true }` |

### 3.5 ショートカットパックの取り込みと一覧

**ファイルの形（`.tpshortcuts`）**：zip で、いちばん上に `shortcuts.json`、あれば `icons\` に画像。zip にしていない `.json` だけのファイルも受け付ける。

```json
{
  "format": "tapoard-shortcuts",
  "version": 1,
  "name": "Blender",
  "author": "",
  "app": "Blender",
  "shortcuts": [
    { "name": "レンダリング", "keys": "F12", "description": "画像を作る", "icon": "render.png" },
    { "name": "元に戻す", "keys": "Ctrl+Z" }
  ]
}
```

- `keys` は「好きなキー」と同じ書き方（`Ctrl`・`Shift`・`Alt`・`Win` と、`hotkeyNames` のキー1つを `+` でつなぐ）。
- **取り込み**（新しい `settings\shortcut-pack-reader.js` と `settings\shortcut-packs.js`）：
  1. 「アプリ別」の2段目のいちばん下に「ショートカットパックを取り込む」ボタン（`.tpshortcuts`・`.json` を選ぶ）。
  2. 読んで確かめる：`format`・`version`（1 だけ）、名前、ショートカットが 1〜300 個。キーがおかしいもの・名前が無いものは飛ばして数える。1つも残らなければ取り込まない。
  3. `icons\` に画像があり、ショートカットが `icon` で指していれば、**同じ名前のアイコンパックを作る**（12 の `IconPacks` の取り込みと同じ道具：`makePackIcon`、`/api/icon-packs/create` と `/add`。指されていない画像は入れない）。アイコンパックの上限などで作れなければ、アイコンなしで続ける（お知らせに書く）。
  4. `POST /api/shortcut-packs/save`。失敗したら、3 で作ったアイコンパックを消す。
  5. お知らせ：取り込んだ数、飛ばした数。
- **一覧**：取り込んだパックは「アプリ別」の2段目に、内蔵の分類の下に並ぶ（名前、`app` と作者、個数）。3段目は内蔵の分類と同じ行。パックの行には「削除」。削除は `ConfirmDialog` で確かめる（「置いてあるボタンはそのまま使えます。一緒に作ったアイコンパックは『見た目』から消せます」と書く）。
- **置いたボタン**：VS Code（3.3）と同じ `key-custom`。名前はショートカットの `name`。アイコンがあれば `iconPack`・`iconPackItem`、無ければ `iconKey: 'keyboard'`。**ボタンはパックを指さない**（キーを自分で持つ）ので、パックを消しても動く。
- 「最近使ったもの」用の id は `pack:<パックの id>:<番号>`。
- 設定ウインドウを開いたときに `GET /api/shortcut-packs` を1回読む。取り込み・削除のあとに読み直す。
