## 3. やること

### 3.1 `GET /api/v3/state`

新しい画面が読む状態です。**配置は v3 の形**、それ以外（音量・PC情報など動いている値）は今の `/api/state` と同じ値を返します。

- ルート表に `GET /api/v3/state`、`ApiAccess.Paired` を足す（46本になる）。処理は `DeckController` に置く。
- 受け取る query は `/api/state` と同じ（`version`、`viewId`、`visibleIds`）。`viewId`/`visibleIds` の扱い（表示の登録・`inputSessions`）も `/api/state` と同じにする。
- 返す形：

```json
{
  "schemaVersion": 3,
  "revision": 12, "version": "…", "appVersion": "4.0.0", "computer": "…",
  "deck": { "keepAwake": false, "landscape": { "columns": 5, "rows": 3, "faders": {…}, "pages": [ { "faders": null, "items": [ … ] } ] }, "portrait": { … } },
  "widgetDefinitions": [ … ],
  "current": { "landscape": 0, "portrait": 0 },
  "background": …, "audio": …, "metrics": …, "weather": …,
  "phoneConnected": true, "pcWindowOpen": false, "inputSessions": [ … ]
}
```

  - `deck` と `widgetDefinitions` は、query の `version` が今の `version` と同じなら**入れない**（`/api/state` が `apps` を省くのと同じ考え方。アイコン画像が大きいため）。
  - `background`・`audio`・`metrics`・`weather`・`inputSessions` などは `/api/state` と同じ作り方・同じ形にする。**同じ処理を2回書かず**、`GetState` から共通部分をメソッドに出して両方から使う（`/api/state` の出力は1文字も変えない。既存テストで確認）。
  - `deck.background` は入れない（上の `background` と重なるため）。
- `deck` は `SettingsMigration.ToV3(state.Config).deck` から作り、**新しいクラス `PublicDeckV3`（`src\PublicDeckV3.cs`）で、スマホに見せてよい項目だけを残した辞書に変える**：
  - ボタン（`DeckItem`）は**残す項目を名前で決める（許可リスト）**：`id name icon iconKey iconColor customIcon type action category deviceId deviceTarget row column width height fontSize iconScale labelOpacity keyClear hideLabel options`。
  - `options` は `WidgetRegistry.PublicOptions` と同じ条件（表示部品だけ）にする。条件を2か所に書かないよう、`AppEntry` を受けている今の判定を type だけで呼べる形に分けて共有してよい。
  - `path`・`args`・`url`・`text`・`hotkey`・`deviceName`・`iconPack`・`iconPackItem` はスマホに出さない（今の `PublicEntry` と同じ）。
  - `row`/`column` は v3 の値そのまま（`SettingsMigration` と同じ数え方）。
- ロック：`state.Gate` の中で `ToV3` と `PublicDeckV3` まで作り、JSON にして返すのはロックの外でよい。

### 3.2 `/v4/` の下のファイルを配る

- 新しい静的クラス `WebFiles`（`src\WebFiles.cs`）を作る：
  - `static string ResolveV4(string webRoot, string path)`：配ってよければ実際のファイルの絶対パス、だめなら `null`。
    - `/v4` と `/v4/` は `v4\index.html`。
    - それ以外は `/v4/` で始まること。使える文字は `A-Z a-z 0-9 . _ - /` だけ（`%`・`\`・`:` があれば null）。`..` を含む、`//` を含む、`.` で始まる部分がある、は null。
    - 拡張子は `.html .js .css .json .png .svg` だけ。
    - `Path.GetFullPath` した結果が `web\v4\` の中にあり、ファイルが実在すること。
  - `static string ContentType(string file)`：`.js` → `application/javascript`（モジュールはこれでないと動かない）、`.json` → `application/json`、`.css` → `text/css`、`.png` → `image/png`、`.svg` → `image/svg+xml`、`.html` → `text/html`。文字のものは UTF-8。
- `Program.Handle` で、`GET` かつ `ResolveV4` が null でなければ、認証なしでそのファイルを返す（今の `PublicFiles` と同じ扱い。画面のファイルに秘密は入れない）。`PublicFiles` と `ServeFile` の今の動きは変えない。
- 新しい画面は `/nosleep.min.js` を使ってよい（今も公開している）。
- `tests\WebFilesTests.cs`（一時フォルダに `web\v4\` を作って確認）：`/v4/` → index.html、`/v4/core/api.js` 可、`/v4/../app.js`・`/v4/%2e%2e/app.js`・`/v4/a\b.js`・`/v4/.hidden.js`・`/v4/x.exe`・`/v4/none.js`（無い）・`/app.js`（v4 の外）がすべて null、`ContentType` の6種類。`tests\run-unit.ps1` の一覧に足す。

### 3.3 骨組み（`web\v4\core\`）

| ファイル | クラス | 役目 |
|---|---|---|
| `api.js` | `Api` | `fetch` に `Authorization: Bearer <キー>` を付ける。`get(path, timeoutMs)`・`post(path, body, timeoutMs)`。JSON を返す。401 は `AuthError`、それ以外の失敗は `ApiError`（`status` と サーバーの `error` 文字を持つ）。タイムアウトは `AbortController`。 |
| `keys.js` | `KeyStore` | 接続キーの読み書き。`localStorage` の `tapoard-key`。URL が `#connect=<キー>` なら保存して `history.replaceState` でハッシュを消す（今の画面と同じ）。`clear()`。 |
| `store.js` | `Store` | 最後に受け取った状態を持つ。`deck` と `widgetDefinitions` は `version` 付きで覚えておき、省かれた応答が来たら前のものを使う。`update(response)`、`get()`、`subscribe(fn)`（戻り値で解除）。 |
| `sync.js` | `SyncLoop` | `GET /api/sync?revision=<n>&viewId=<id>` を待ち続け、変わったら `GET /api/v3/state?version=…&viewId=…` で読み直して `Store` に入れる。画面が隠れたら止め、見えたらすぐ読み直してから再開。失敗したら 1・2・4・8・10 秒…（最大10秒）待って再試行し、つながらない間は `onOffline(true)` を呼ぶ。`AuthError` なら止めて `onAuthLost()`。 |
| `view-id.js` | ― | 今と同じ `sessionStorage` の `tapoard-view-id`（8〜64文字の英数 `_-`）を返す。無ければ作る。 |
| `i18n.js` | `I18n` | 下の 3.6。 |
| `dom.js` | ― | `el(tag, className, text)` などの小さな関数だけ。 |

- `I18n` と `Store` は DOM も `fetch` も直接使わないこと（読み込み関数を外から渡す）。node のテストでそのまま読み込むため。

### 3.4 ボタンの並び（`web\v4\deck\`）

- `grid.js`：`class DeckGrid`。`render(container, orientationDeck, pageIndex, widgetDefinitions)`。
  - CSS grid で `columns × rows`。各ボタンを `row`/`column`/`width`/`height` の位置に置く（`grid-row: row+1 / span height` の形）。
  - フェーダー：ページの `faders` があればそれ、`null` なら向きの `faders` を使う。`off`/`speakerHidden`/`micHidden` のものは出さない。今回は**枠だけ**（アイコンと「スピーカー」「マイク」の文字）。
  - 部品（`widgetDefinitions` に type がある物と、`wheel`・`touchpad`・`keypad` など今の画面で部品として描いている type）は**枠だけ**（名前と「この部品は準備中です」）。08 で中身を作る。
  - ふつうのボタン：アイコン＋名前（`hideLabel` なら名前なし）。`fontSize`・`iconScale`・`labelOpacity`・`keyClear` は今の画面と同じ意味で反映する（見た目は今と細かく同じでなくてよい）。
  - 押したとき：指を動かさずに離したら `onPress(item)`。スワイプ中・長押し中は呼ばない。
- `icons.js`：今の `app.js` の `presetGroups`・`presetPaths`・`widgetGlyphs`・`shortcutGlyph` の**データと描き方を移す**（コピーでよい。古い画面は 13 で消す）。`export function iconNode(item)`：`customIcon` → `<img>`、`iconKey` → 内蔵アイコン、`icon` → `<img>`、`type === 'hotkey'` → 分類の記号、どれでもなければ名前の1文字目。画像の `src` に使ってよいのは `data:image/` で始まる文字か同じサーバーのパスだけ。
- 押したら `POST /api/action` に `{ "action": "launch", "id": <id> }`（今の画面と同じ）。押した感触：`navigator.vibrate(10)`（使えれば）＋押した見た目。失敗したら下に短く出す（言語ファイルの文字＋サーバーの `error`）。

### 3.6 言語ファイル

- `web\v4\i18n\ja.json`・`en.json`：`{ "menu.keepAwake": "画面を維持", "deck.page": "{current} / {total}", … }` のような**1段の**キーと文字。`{name}` で差し込み。
- `I18n`：
  - 言語の決め方：`tapoard-lang` が `ja`/`en` ならそれ。`auto` か無ければ、`navigator.language` が `ja` で始まれば `ja`、それ以外は `en`。

- 今回の画面に出る文字はすべて両方のファイルに入れる。英語は自然な短い英語で。
