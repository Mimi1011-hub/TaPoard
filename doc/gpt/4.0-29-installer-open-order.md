# 4.0-29 インストール完了の後で TaPoard の画面を開く

作業の決まりは `doc/gpt/4.0-00-working-rules.md` のとおり（外部パッケージ禁止、C# 5、1行160文字以内、画面の文字は日本語・英語とも辞書に入れる。機械翻訳は使わない）。
ブランチ: その時点の `develop/4.0` から `gpt/4.0-29-installer-open-order` を切る（指示書 27・28 とは別のブランチ）。
コミットの作者は「TaPoard Developer」と GitHub の noreply アドレス。Co-Authored-By などの行は入れない。
項目ごとにコミットする。上から順に行う。

Hiro の指摘: インストールすると、先に TaPoard の画面（PC ウインドウ）が開き、その後で「インストールが完了しました」が出る。順番がおかしい。

原因: `installer/Installer.cs` の `Install()` は、アプリが動くかを確かめるため（`network.json` ができるのを待つ）と、
ファイアウォールの設定のためにアプリを先に起動する。アプリは起動すると `StartupMode()` に従って PC ウインドウを開く（`src/Program.cs` の `Main`）。
完了の知らせはその後に出る。また、2つ目のアプリは `Mutex` を見て何もせずに終わるので、動いているアプリの画面を後から開く方法が無い。

## 1. アプリ: 画面を開かずに起動する `--installing`

- `Main` の引数に `--installing` があれば、サーバー・トレイのアイコンは今どおり始めるが、PC ウインドウもブラウザの設定も開かない。
- それ以外の起動（引数なし・`--silent`）は今のまま。

## 2. アプリ: 2つ目の起動で、動いているアプリの画面を開く

- 名前付きのイベント（例: `EventWaitHandle`、名前 `Local\TaPoard.Show`）を最初のアプリが持ち、別のスレッドで待つ。
  合図が来たら UI のスレッド（`ui.BeginInvoke`）で、トレイの「PC ウインドウを開く」と同じ動き（`OpenPcWindowFromTray()`）をする。
  前に出ていなければ前に出す。開けないとき（WebView2 が無いなど）は今のトレイのときと同じ扱い。
- 2つ目のアプリは `Mutex` が取れなかったとき、引数に `--silent` が無ければこの合図を送ってから終わる。`--silent` なら何もしないで終わる（Windows の起動時の自動起動のため）。
- これで、動いている間にデスクトップのショートカットを押したときも画面が出るようになる（今は何も起きない）。
- テスト（C#）: 合図を送る・受ける部分を小さなクラスにして（例: `src/SingleInstance.cs`）、合図で呼び出しが1回起きること、`--silent` では送らないことを確かめる。

## 3. インストーラー: 完了を知らせてから画面を開く

- アプリの起動を `--installing` 付きにする（`network.json` を待つ処理・失敗のときの `startFailed` は今のまま）。
- 最後の完了の知らせ（`done` / `doneNoFirewall` / `adminCancelled` / `lanFailed` のどれでも）で OK を押した後に、
  もう一度 `AppPath` を引数なしで起動する（2 の合図で、動いているアプリが画面を開く）。`startFailed` のときは開かない。
- `done` の文が古い（「PCのブラウザに表示されたQRコード」。今はブラウザは開かない）ので直す:
  - 日本語: 「インストールが完了しました。\n\nOK を押すと TaPoard の画面が開きます。スマートフォンは、設定の「接続」に出る QR コードを読み取るとつながります。」
  - 英語: "Installation is complete.\n\nTaPoard opens when you click OK. To connect your phone, scan the QR code under Connection in Settings."
  - 「接続」の名前は今の設定ウィンドウのタブの名前に合わせる（違っていたら合わせて直す）。
  - `doneNoFirewall` にも「OK を押すと TaPoard の画面が開きます。」（英: "TaPoard opens when you click OK."）を足す。
- 今の Windows の起動時の自動起動（`--silent`）は変えない。

## 4. テスト

- 既存のテストをすべて通す（`tests/run-unit.ps1`、`node tests/*.mjs`、`tests/v4-*-ui.cjs`、`test.ps1`）。
- Hiro の PC での確認: `package.ps1` で作ったインストーラーで入れ直し、「インストールが完了しました」が先に出て、OK の後に PC ウインドウが開くこと。
  TaPoard が動いている間にデスクトップのショートカットを押すと PC ウインドウが出ること。結果を報告に書く。
