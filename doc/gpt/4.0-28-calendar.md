## 1. 予定のデータ（PC 側）

- 保存先は `data\calendar.json`（`src/CalendarStore.cs`）。形:
  `{ "version": 1, "events": [ { "id", "title", "start", "end", "allDay", "color", "source" } ] }`
  - `start` / `end` は `yyyy-MM-dd`（終日）か `yyyy-MM-ddTHH:mm`（PC の地域の時刻）。`end` は無くてもよい。
  - `title` は 1〜80 文字。`color` は今のアイコンの色と同じ検査。`source` は `"manual"` か読み込んだファイルの名前（40 文字まで）。
  - 予定は 2000 件まで。毎週・毎月などの繰り返しは、今回は「毎年」（誕生日など）だけ対応する（`repeat: "yearly"`）。
- `.ics` の読み込み: `VEVENT` の `SUMMARY` `DTSTART` `DTEND` `RRULE:FREQ=YEARLY` だけを読む（自分で読む。外部のライブラリは使わない）。
  - `DTSTART;VALUE=DATE:20261117`（終日）、`DTSTART:20261117T010000Z`（UTC → PC の時刻に直す）、`DTSTART;TZID=Asia/Tokyo:20261117T100000`（その地域の時刻）に対応。
    `TZID` は Windows の `TimeZoneInfo` で読めるものだけ。読めなければ PC の時刻として扱う。
  - 行の折り返し（次の行が空白で始まる）と `\,` `\n` などの戻しに対応する。
  - `FREQ=YEARLY` 以外の繰り返し（毎週など）は、最初の1回だけ入れ、読み込みの結果に「繰り返しの予定 N 件は最初の1回だけ入れました」と出す。
  - 1 ファイル 2MB まで。同じファイル名から読み込み直したときは、前にそのファイルから入れた予定を置き換える（手で書いた予定は消さない）。
  - 説明（`DESCRIPTION`）、場所、参加者のメールアドレスなどは読まない・保存しない（個人の情報を持たないため）。
- 日本の祝日: 「日本の祝日を出す」を選べるようにする（既定は、言語が日本語ならオン）。祝日は法律の決まり（固定の日、ハッピーマンデー、
  春分・秋分の日の計算式、振替休日、国民の休日）から計算する（`src/JapaneseHolidays.cs`）。データをネットから取らない。2000〜2099 年。
- API（どれも `ApiAccess.Admin`、表示用だけ `Paired`）:
  - `GET /api/calendar`（Admin）: すべての予定と設定。
  - `POST /api/calendar/save` / `delete` / `import`（`.ics` の中身を base64）/ `remove-source`（読み込んだファイルの予定をまとめて消す）/ `options`。
  - 表示用: 端末には、部品が表示している月（前後の月を含む）の予定の `title` `start` `end` `allDay` `color` と祝日の名前だけを送る（表示の同期で）。
  - `ApiRouteTableTests` に足す。
- テスト（C#）: `.ics` のいろいろな形（終日、UTC、TZID、折り返し、エスケープ、毎年、毎週、壊れたファイル）、2000 件の上限、
  ファイルの読み込み直しで手書きの予定が残ること、祝日の計算（2026 年と 2027 年の全祝日、振替休日、国民の休日）。

## 2. 部品（スマホ・PC ウインドウ）

`web/v4/widgets/calendar.js`、`WidgetRegistry` に `calendar`（「カレンダー」/ "Calendar"）。

- 表示の種類（オプション `view`）:
  - `month`（月）: 3×3、4×3、4×4。月の見出し、曜日、日付のマス。今日は強調の色の丸。予定のある日は小さな点（予定の色）。祝日と日曜は赤、土曜は青（日本語のとき）。
    左右の小さな矢印で前後の月へ。押したまま 5 秒たつか、ページを移ったら今月に戻る。
  - `agenda`（予定の一覧）: 2×2、3×2、4×2、2×3。今日から先の予定を、日付ごとに時刻と題名で並べる。入りきらない分は「ほか N 件」。
  - `today`（今日）: 2×1、2×2。今日の日付・曜日と、今日の予定の数と次の予定1件。
- 週の始まり（オプション `weekStart`: `sunday` / `monday`、既定は日曜）。
- 日付が変わったら自動で今日に動く（時計の部品と同じく、画面側で日付の変わり目を見る）。
- 指示書 23 のスワイプ: 月の矢印の上からはスワイプしない。ほかの所からはスワイプできる。

## 3. 設定ウィンドウ

- カタログの「部品」に「カレンダー」（月・予定の一覧・今日）を置く。
- カレンダーの部品の詳細欄に「予定を管理」ボタン。押すと、右のプレビュー欄が予定の管理の画面に変わる（AI のアイコンの案内と同じく、見出しの隣に「戻る」）。
  - 月ごとの一覧。予定の追加（題名、終日か時刻つきか、日付と時刻、色、毎年）・変更・削除。
  - 「.ics を読み込む」。読み込んだ結果（入れた件数、最初の1回だけ入れた繰り返しの件数、読めなかった件数）を出す。
  - 読み込んだファイルごとの一覧と「このファイルの予定を消す」。
  - 「日本の祝日を出す」のチェック。
  - 説明の文: 「Google カレンダーなどの予定は、そのサービスで .ics ファイルを書き出して読み込めます。自動では同期しません。」
- 設定のプレビューでは本物の予定を出してよい（PC の中だけなので）。
