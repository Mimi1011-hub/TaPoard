作業の決まりは `doc/gpt/4.0-00-working-rules.md` のとおり（外部パッケージ禁止、C# 5、1行160文字以内、JS 1ファイル300行以内、画面の文字は日本語・英語とも辞書に入れる。機械翻訳は使わない）。
ブランチ: `develop/4.0` から `gpt/4.0-27-now-playing` を切る。
コミットの作者は「TaPoard Developer」と GitHub の noreply アドレス。Co-Authored-By などの行は入れない。
項目ごとにコミットする。上から順に行う。
UI テストの偽の PC は、本物と同じ形を返し、本物と同じものを断ること（指示書 20 の決まりのまま）。

Hiro の希望: PC で今かかっている曲（Spotify、YouTube Music をブラウザで、Apple Music、Windows のメディア プレーヤーなど）を、
アルバムの絵つきでスマホと PC ウインドウに出し、そこから再生・一時停止・前・次を操作したい。予定では 4.2 の後だったが、4.0 に入れる。

## 0. 先に確かめること（ここで止まったら、作らずに報告する）

Windows が「今再生中のもの」を知らせる仕組みは WinRT の `Windows.Media.Control.GlobalSystemMediaTransportControlsSessionManager`
（Windows 10 1809 以降）しか無い。外部パッケージは使えないので、Windows に入っているものだけで使う:

- コンパイルは今と同じ `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。参照に次を足す:
  - `C:\Windows\System32\WinMetadata\Windows.Media.winmd`、`Windows.Foundation.winmd`、`Windows.Storage.winmd`（サムネイルの読み出し）
  - `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\System.Runtime.WindowsRuntime.dll` と `System.Runtime.dll`（`IAsyncOperation` を待つため）
- C# 5 なので `async/await` は使ってよいが、`IAsyncOperation<T>` は `WindowsRuntimeSystemExtensions.AsTask()` で `Task` にしてから待つ。
- **最初のコミットで、これだけを試す小さな作り（今の曲名をログに出すだけ）を入れ、`build.ps1` と `package.ps1` でビルドでき、
  Hiro の PC で曲名が取れることを確かめる。** ビルドできない・取れないときは、そこで止めて、何が出たかを報告する（ほかの方法を勝手に探さない）。
- WinRT を使うコードは `src/winrt/` の1ファイル（例: `src/winrt/MediaSessionWinRt.cs`）だけに閉じ込める。
  `build.ps1` / `package.ps1` は `src\*.cs` に加えて `src\winrt\*.cs` をコンパイルし、上の参照を付ける。
  ほかのコードは `IMediaSession`（下の 1）だけを見る。テスト（`tests/run-unit.ps1`）は `src\*.cs` だけをコンパイルし、偽物の `IMediaSession` を使う
  （クロの確認環境では WinRT をコンパイルできないため）。`AppHost` で本物か偽物かを差し替える（今の `IAudioDevices` などと同じ）。
- Windows のバージョンが古くて使えないとき（型が読めない・例外）は、部品に「この PC では使えません」と出し、アプリは落ちないこと。

## 1. PC 側（C#）

- `IMediaSession`（`src/MediaSession.cs`）:
  - `MediaState Current()`: 今のセッションの `title` `artist` `album` `app`（再生しているアプリの名前。分かれば「Spotify」など、分からなければ空）
    `playing`（再生中か）`canPlayPause` `canNext` `canPrevious` `position` `duration`（秒、分からなければ null）`artVersion`（絵が変わったら変わる短い文字列）。
    再生しているものが無いときは `active: false`。
  - `byte[] Art()`: アルバムの絵。PNG か JPEG に直し、長い辺を 320px までに縮める（`System.Drawing`）。無ければ null。メモリに1枚だけ持つ。
  - `void Command(string name)`: `playPause` / `next` / `previous`。セッションのメソッド（`TryTogglePlayPauseAsync` など）を使い、
    使えないときは今のメディアキー（`MediaPlayPause` など）を送る。
- 取りに行く間隔: 部品を表示している端末があるときだけ、1 秒ごと（今の天気・PC 情報の `DisplaySubscriptions` と同じ仕組みに `media` を足す）。
  表示している端末がなければ止める。変わったときだけ同期（`SyncHub`）で知らせる。
- API:
  - 状態は今の部品と同じ流れ（表示の同期）で端末に送る。曲名などはつないだスマホと PC ウインドウにだけ送る（今の PC 情報と同じ扱い）。
  - `GET /api/media/art?v=<artVersion>`（`ApiAccess.Paired`）: 絵を返す。`Cache-Control` は `private, max-age=3600`。無ければ 404。
  - `POST /api/media/command`（`ApiAccess.Paired`）: `{ "command": "playPause" | "next" | "previous" }`。ほかは 400。「見るだけ」の端末からは断る（今のボタンと同じ）。
  - `ApiRouteTableTests` に足す。
- `WidgetRegistry` に `nowPlaying`（表示: 「再生中の曲」/ "Now playing"）を足す。大きさは `2x1`、`2x2`、`3x2`、`4x2`、`3x3`、`4x3`、`4x4`（Hiro の希望で 4×4 まで）。
  オプション: `showArt`（既定 true）、`showControls`（既定 true、2x1 では無視）、`showProgress`（既定 true）。ほかの値は断る。
- テスト（C#）: 偽の `IMediaSession` で、状態の形、絵の縮小（大きい画像を入れて 320px 以下）、コマンドの検査、表示している端末が無いと取りに行かないこと、
  `WidgetRegistry` の大きさとオプションの検査。

## 2. 画面（スマホ・PC ウインドウ）

`web/v4/widgets/now-playing.js` を作り、`registry.js` に登録する（今の天気・PC 情報と同じ作り）。

- 2×1: 左に小さな絵、右に曲名（1行）とアーティスト（1行）。押すと再生・一時停止。
- 2×2: 絵を全体に敷き、下に暗いグラデーションを重ねて曲名・アーティスト、その下に「前・再生/一時停止・次」の3つのボタン、細い進み具合の線。
- 3×2 / 4×2: 左に正方形の絵、右に曲名・アーティスト・アルバム・アプリ名、下に3つのボタンと進み具合の線。
- 3×3 / 4×4: 上に大きな正方形の絵（真ん中に置く）、その下に曲名（大きめ）・アーティスト・アルバム、進み具合の線と経過時間 / 長さ（例 1:23 / 3:45）、
  一番下に3つの大きなボタン。音楽アプリの再生画面のような見た目にする。
- 4×3: 左に正方形の絵（高さいっぱい）、右に曲名・アーティスト・アルバム・アプリ名、経過時間 / 長さ、3つのボタン。
- 何も再生していないとき: 音符のアイコンと「再生中の曲はありません」（英: "Nothing is playing"）。
- この PC で使えないとき: 「この PC では使えません」（英: "Not available on this PC"）。
- 曲名が長いときは省略（…）。流れる文字にはしない。
- 進み具合は 1 秒ごとに PC から来る値で動かし、間は画面側で進める（再生中だけ）。
- ボタンを押したときは、今のボタンと同じ押した感触（振動・音）を出す。
- 絵は `<img>` で `/api/media/art?v=...` を読む。`artVersion` が変わったときだけ読み直す。
- 指示書 23 のスワイプ: この部品のボタンの上からはスワイプしない。絵や文字の上からはスワイプできる。

## 3. 設定ウィンドウ

- カタログの「部品」に「音楽」の分類を足し、「再生中の曲」を置く（大きさは 2×1 / 2×2 / 3×2 / 4×2 / 3×3 / 4×3 / 4×4 から選ぶ）。
- 詳細欄: 「アルバムの絵を出す」「操作のボタンを出す」「進み具合を出す」のチェック。
- 設定のプレビューでは、見本の曲（絵は単色の四角と音符、曲名「曲名」アーティスト「アーティスト」）で表示する。本物の曲は出さない。
- 説明（カタログ）: 「PC で再生中の曲を表示して操作します」。指示書 25 のボタンの説明にも出る。

## 4. テスト

- UI テスト（`tests/v4-widgets-ui.cjs`）: 偽の PC が本物と同じ形の状態を返し、7つの大きさすべてで曲名・絵・ボタンが出て、はみ出さない（4×4 では経過時間も出る）。ボタンで `POST /api/media/command` が送られる。
  再生していないとき・使えないときの表示。絵の URL が `artVersion` で変わる。
