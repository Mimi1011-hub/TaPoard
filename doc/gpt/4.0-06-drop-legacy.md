## 3. やること

### 3.1 `/api/layout` を管理者だけにする

- ルート表の `POST /api/layout` を `ApiAccess.Admin` にする。
- `tests\ApiRouteTableTests.cs` の期待値を `POST /api/layout Admin` に直す（ほかの44本は変えない）。
- `tests\ApiStatusTests.cs` に「端末のキーで `POST /api/layout`（本文 `{}`）→ 403」を足す。
- `SetLayout` の中で `r.isAdmin` によって分けている所は、管理者しか来ないので整理してよい（動きは管理者から見て今と同じ）。

### 3.2 12文字の短いキーをなくす

3.1 までは、48文字の接続キー（token）のほかに、12文字の `pairingKey` でも接続できました。4.0 では token と、承認済み端末の認証情報だけにします。

- `Settings.pairingKey` と `SecurityV3.pairingKey` を消す。`ShortKey()`（Program と DeckView の両方）と、起動時・キー再発行時に作る処理を消す。
- `Authenticate` の `|| r.auth == "Bearer " + State.Config.pairingKey` を消す。
- 引き継ぎ（`DeckController` の `KeepServerFields`、`LookController` / `PageController` の復元）、`IconStyles` の `copy.pairingKey = null` を消す。
- **05 で作った `settings-v3.json` には `security.pairingKey` が入っている**。読み込みはエラーにせず（`JavaScriptSerializer` は知らない項目を無視するので、そのまま読めるはず）、次の保存で消えること。
- `SecureKeys.Short` がほかで使われていなければ消す。
- テスト：
  - `tests\ApiStatusTests.cs`：`Bearer <12文字の古いキー>` で `GET /api/ping` → 401。
  - `tests\SettingsV3Tests.cs`：`security.pairingKey` 付きの v3 を読める → 保存した v3 に `pairingKey` が出てこない。
  - ほかのテストの `pairingKey = ...` は消す。
- `test.ps1`：`$shortHeaders` と 12文字キーの確認（6〜7行目と、それを使っている所）を消し、代わりに「`Bearer ABCDEFGHJKLM` で `/api/ping` が 401」を確かめる。

### 3.3 スマホのメニュー

- `web\index.html` の `#device-menu-backdrop` から「ボタンの枠数」の `menu-card`（`grid-columns` / `grid-rows`）を消す。`web\app.js` の `grid-columns` / `grid-rows` の処理も消す（設定画面の `admin-columns` / `admin-rows` は残す）。
- 「画面を維持」（`#awake`）は、スマホでは**この端末だけの設定**にする：
  - `localStorage` の `tapoard-keep-awake`（`'1'` / `'0'`）に保存し、スマホからは `/api/layout` を呼ばない。
  - まだ保存されていない端末は、今までどおりサーバーの `keepAwake` を初期値にする。
  - 説明文を「この端末の画面を自動で消さない（この端末だけの設定）」にする。
  - 設定画面（管理者）側の `keepAwake` の扱いは今のまま。
- メニューの一番下に1行足す：「ボタンの追加・配置・枠数の変更は、PCの設定画面で行います。」
- UI テスト（`tests\*-ui.cjs`）でスマホの枠数を変えているものがあれば、設定画面から変える形に直すか、その確認を消す。

### 3.4 旧 StreamDeck の名前

- `web\app.js`：`streamdeck-admin`、`streamdeck-key`、`streamdeck-preview-orientation` を読む・消す処理をすべて消す（`tapoard-…` だけを使う）。
- `src\LanNetwork.cs`：`streamdeck-` で始まる名前を `tapoard-` へ直す処理を消す。
- `setup-lan.ps1`：古いファイアウォール規則（`StreamDeck-LAN-HTTP` / `StreamDeck-LAN-mDNS`）を消す処理を消す。
- **`.streamDeckIconPack` の読み込みは残す**（他のソフトのアイコンパック形式を読む機能で、互換ではないため）。
- 終わったら、`src\`・`web\`・`installer\`・`*.ps1` で `streamdeck` を大文字小文字を無視して検索し、`.streamDeckIconPack`（とそのテスト）以外に残っていないこと。

### 3.5 変換の安全

`SettingsMigration.ToOrientation` は、`orientation` が `landscape` / `portrait` のどちらでもないボタンを黙って飛ばしています。今は入口（`ValidateEntry`）で止めているので起きませんが、保存で設定が消えるのを防ぐため、**どちらの向きにも入らなかったボタンがあれば例外**にする。`tests\SettingsV3Tests.cs` に確認を足す。
