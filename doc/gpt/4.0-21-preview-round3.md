## 0. バージョンの表示からコンピューター名を外す

「全般」タブのバージョンの表示が「バージョン 4.0・PC <コンピューター名>」になっている。コンピューター名は出さない（Hiro の指示）。

- 表示は「バージョン {version}」だけにする（`general.versionComputer` をやめ、`general.version` などに置き換える。日本語・英語とも）。
- PC 側の `/api/v3/state` の応答から `computer`（`Environment.MachineName`）を外す（`DeckController.cs` の `DeckRuntimeState.computer` と `GetV3State`）。
  この応答はつないだスマホにも返るので、使わない PC の名前を送らない。
- テストの偽の PC の `computer` も外し、`computer` が応答に無いことを C# テストで確かめる。

## 1. 不具合: テンキーのキーが細い

テンキーを置くと、キーが上下に細い帯になり、行の間が大きく空く（スマホ画面・PC ウィンドウ・プレビューとも）。

原因: `web/v4/style/deck.css` の `.widget-tile` に `align-items: center` があり、`.keypad-widget`（grid）が `align-items` を上書きしていないので、
キーが行の高さいっぱいに伸びず、文字の高さだけになる。3.1 の `.keypad-widget` には `align-items: stretch; justify-items: stretch;` があった。

直し方:
- `.keypad-widget` に `align-items: stretch; justify-items: stretch;` を足す。
- ほかのウィジェット（タッチパッド、ホイール、スライドショー、時計、天気、PC 情報）も同じ原因で縮んでいないか、3.1 の `web/style.css` と見比べて確かめる。
- UI テスト: 4×4 と 4×5 のテンキーで、キーの高さが行の高さの 80% 以上あること。

## 2. 不具合: ページのタブが番号のところしか押せない

ページのタブは「1 …」「2 …」のようになっていて、番号の部分を押したときだけページが切り替わる。「…」はメニュー（名前を変える・削除など）を開くボタンなので、そこを押すと切り替わらずメニューが出る。

直し方:
- タブの番号・名前の部分は、余白も含めてタブの幅いっぱいを押せるようにする（ボタンを `flex: 1` で広げる）。
- メニューのボタンは小さくし、記号を「⋮」にして、名前の省略記号「…」と見分けられるようにする。マウスを乗せたときに「ページのメニュー」と出す。
- UI テスト: タブの右端近く（メニューのボタン以外）を押しても切り替わる。

## 4. スマホの画面比率に機種の例を出し、おすすめの枠数を出す

プレビューの「見え方」をスマートフォンにしたときの「画面比率」の一覧に、比率だけでは分かりにくいので代表的な機種を添える。
枠数が比率に合っていないと、スマホで枠が横長（縦長）になるので、おすすめの枠数を出す。

- 一覧の文字を次のようにする（日本語・英語とも。機種名は英語のまま）。
  - 自動（最後につないだスマホ: 幅×高さ）
  - 16:9（iPhone 8・iPhone SE 第2/第3世代 など）
  - 18:9（Pixel 3 など少し前の Android）
  - 19.5:9（iPhone X 以降の iPhone・Galaxy S シリーズ など）
  - 20:9（Pixel 7 以降・多くの Android）
  - 4:3（iPad）
- 一覧の横に「おすすめの枠数」を出す。選んでいる比率と向きから、マスがほぼ正方形になる枠数を計算して2～3通り出す
  （例: 横向き 19.5:9 なら 行 3 → 列 6 か 7、行 4 → 列 8）。列は 3～8、行は 2～5 の範囲。
  それぞれ押すとその向きの枠数をその値に変える（今の枠数の変更と同じ確認・元に戻すが効くこと）。
- 今の枠数でマスが正方形から 25% 以上ずれるときは、プレビューの下に「スマホではマスが横長（縦長）になります」と出す。
- テスト: おすすめの枠数の計算（node のテスト）、押すと枠数が変わる（UI テスト）。

## 5. AI でアイコンを作る方法の案内

アイコンパックのタブの「アイコンの一括変更」の下に、「AI でアイコンファイルを作る方法」ボタンを置く。
押すと、右のプレビュー欄が案内の画面に変わる（プリセットのプレビューと同じく、見出しの隣に「戻る」）。

- 案内の中身（日本語と英語。文はクロが確認するので、自然な文で書くこと）:
  1. TaPoard のアイコンの名前（キー）の一覧を書き出すボタン。`icons.json` のひな形（`format: "tapoard-icons"`、各アイコンの `key` と `name`、`file` は `icons/<key>.png`）を保存できる。
  2. 画像を作れる AI（名前は出さない）に頼むときの文の例。コピーするボタン付き。例:
     「正方形 512×512 の PNG で、背景は透明、同じ絵柄で統一したアプリのアイコンを作ってください。作るもの: 再生、一時停止、マイク、…」
     一覧はひな形のキーの名前から作る。
  3. できた画像をキーの名前で保存し、`icons.json` と一緒に zip にまとめ、拡張子を `.tpicons` にする。またはそのまま画像をまとめて選んでも読み込める（今の読み込みの決まりに合わせて書く）。
  4. 「アイコンパックを読み込む」で読み込み、「アイコンの一括変更」で使う。
  5. 注意: AI で作った画像の使い方は、その AI のサービスの決まりに従うこと。人に配るときは特に確かめること。
- 案内はすべてこの PC の中だけで表示する（外部のサイトを開かない）。
