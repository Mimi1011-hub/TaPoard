TaPoard 4.0 README
==================

TaPoard は、家庭内 LAN で Windows PC をスマートフォンから操作するためのコントロールパネルです。

初回の接続
----------

1. PC とスマートフォンを同じ通常の Wi-Fi または LAN へ接続します。
2. 通知領域の TaPoard を右クリックし、「設定を開く」を選びます。
3. 設定ウインドウの「接続」にある QR コードをスマートフォンで読み取ります。
4. 接続の申請が表示されたら、双方の確認番号が同じことを確かめ、PC で許可します。

QR コードが開けない場合は、直接 IP 接続用の QR コードを使うか、表示された URL と接続キーを入力してください。

使い方
------

スマートフォンは、配置されたボタンや部品を押して操作するための画面です。ボタンの追加、並べかえ、削除、詳しい設定は PC の設定ウインドウで行います。

設定ウインドウの左側には「配置」「見た目」「保存」「接続」「PC画面」「全般」があります。アプリや URL、4分類の操作一覧、VS Code の操作、ショートカットパック、背景、保存した見た目、PC 用ウインドウなどを設定できます。

言語は「全般」で、自動、日本語、English から選べます。3.1 の設定は、4.0 の最初の起動時に自動で引き継がれます。

つながらないとき
------------------

PC とスマートフォンが同じネットワークにいることを確認してください。ゲスト Wi-Fi は端末同士の通信を禁止していることがあります。VPN を一時的に切り、直接 IP 接続用の QR コードも試してください。

自宅のネットワークは Windows で「プライベート」に設定し、TaPoard のファイアウォール通信を許可してください。設定ウインドウの「接続」から状態の確認と修復ができます。

安全のため
----------

信頼できる家庭内 LAN だけで使ってください。ルーターのポート転送は設定しないでください。LAN 内の HTTP 通信自体は暗号化されません。接続キーを再発行すると、接続中のスマートフォンは切断されます。

アンインストール
----------------

Windows の「インストールされているアプリ」、またはスタートメニューの「TaPoardをアンインストール」から削除できます。
