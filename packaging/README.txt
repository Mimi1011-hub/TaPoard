TaPoard 3.1 README
==================

TaPoardは、Windows PCをiPhoneまたはAndroidのブラウザから操作する
家庭内LAN専用の軽量コントロールパネルです。

初回の接続
----------

1. PCとスマートフォンを同じ通常のWi-Fi／LANへ接続します。
2. 通知領域のTaPoardを右クリックし「設定をブラウザで開く」を選びます。
3. まず左側の「新しいスマートフォン用」QRコードを読み取ります。
4. 左側が開けない場合は、右側の「左のQRが使えない場合」を読み取ります。
5. QRコードが使えない場合は、表示されたURLと接続キーを手入力します。

ホーム画面から開いたときに接続キーの入力画面になった場合
--------------------------------------------------------

1. 「PCに接続をリクエスト」を押します。
2. スマートフォンとPC設定画面に表示された6桁の確認番号が同じことを確認します。
3. PC設定画面で「許可」を押します。次回からその端末は自動接続します。
4. 使わなくなった端末は、PC設定画面の「承認済みの端末」から解除できます。

確認番号は3分で期限切れになります。自分で操作していないリクエストや、番号が違うリクエストは許可しないでください。

ボタンを追加する
----------------

・PC設定画面のスマートフォン画面にある「＋」または空き枠を押します。
・開いた小さな画面へデスクトップのショートカットやexeをドロップします。
・同じ画面の「URLを入力して追加」でURLを入力するか、ブラウザのURLをドロップすると、そのページを開くボタンになります。
・右側のショートカット一覧から空き枠へドラッグして追加することもできます。
・「URL・テキスト」から、Webサイトを開くボタンや定型文をコピーするボタンを追加できます。
・Discordの「サウンドボードを開く」は、ゲームオーバーレイを有効にして使用します。
・登録済みボタンを右クリックすると、移動、削除、アイコン変更ができます。
・登録済みボタンは、PCのスマートフォン画面で空き枠へドラッグして自由に移動できます。
・「＋ ページ」で空のページを追加できます。

ボタンの詳細設定（1.03）
--------------------------

・横向きと縦向きで、登録するボタン、位置、大きさ、文字、アイコン、キー設定を別々に編集できます。
・1.03の従来設定は初回起動時に横向き用と縦向き用へ複製され、その後はそれぞれ独立して保存されます。
・ボタンを1マス（1×1）または4マス（2×2）へ変更できます。
・文字サイズとアイコンの大きさを変更し、文字を隠してアイコンだけにもできます。
・ショートカットボタンは、修飾キーと通常キーを変更できます。「標準に戻す」で元の割り当てへ戻ります。
・4マス分の空きがない場合や、ほかのボタン・フェーダーと重なる場合は保存されません。先に空き枠へ移動してください。
・4マスへ変更した位置からはみ出す場合は、同じ向きの画面内にある4マス分の空き枠へ自動移動します。
・スピーカー／マイクフェーダーの位置と1マス／4マス表示も、横向きと縦向きで別々に保存されます。

アイコン
--------

・アプリ本来のWindowsアイコンを自動取得します。
・92種類のプリセットアイコンを選択できます。
・PNG、JPEG、WebPのオリジナル画像も登録できます。
・「自動取得」を選ぶと元のアイコンへ戻ります。

普段の使い方
------------

・TaPoardは通常、Windowsの通知領域に常駐します。
・スピーカー／マイクの枠は上下スワイプで音量を変更し、アイコン部分でミュートを切り替えます。
・終了するときは通知領域のTaPoardを右クリックし「終了」を選びます。
・スマートフォンへのアプリのインストールは不要です。

接続できない場合
----------------

・PCとスマートフォンが同じネットワークにいるか確認します。
・ゲストWi-Fiでは端末同士の通信が禁止されている場合があります。
・VPNを一時的に切って確認します。
・左側のQRが開けない場合は、右側の直接IP接続を使います。
・直接IPが変わった場合は、PC設定画面を開き直してQRを読み直します。

安全について
------------

家庭内LANだけで使用してください。ルーターのポート転送は設定しないでください。
接続キーを再発行すると、現在接続しているスマートフォンは切断されます。
PCで承認した端末には端末専用の認証情報を発行し、PCにはそのハッシュだけを保存します。
家庭内LANのHTTP通信自体は暗号化されないため、外部公開やルーターのポート転送はしないでください。

アンインストール
----------------

Windowsの「インストールされているアプリ」またはスタートメニューの
「TaPoardをアンインストール」から削除できます。

音声機器の切り替え（1.02）
--------------------------
PCの右側「スピーカー・マイク」にある「出力先を切替」「入力先を切替」を追加、または空き枠へドラッグします。詳細設定の一覧で機器を選び、表示名を確認して「設定を保存」を押します。スマートフォンでボタンを押すと、その機器へ直接切り替わります。
Windowsの通常用・通話用の既定デバイスを切り替えます。Discordやゲームで機器を個別指定している場合、その指定は変わりません。未接続の機器は使用できません。ドライバー更新等で機器IDが変わった場合は一覧から選び直してください。Windowsの非公開インターフェイスを使用するため、Windows更新によって動作しなくなる可能性があります。
アイコンにはヘッドセット・イヤホン・USBマイクなど16種類を追加しました。「アイコンを選ぶ」でプリセットと背景色（標準＋9色）を選べます。背景色はアプリから取得した画像・オリジナル画像には適用されません。

部品（2.0）
-----------
・右側のショートカット一覧の「時計・情報表示」「マウス操作」から追加します。
・時計：デジタル／アナログ（2×2）。
・天気：現在の天気（1×1）と3日間の天気（2×2）。PC設定画面で地域を検索して選びます。予報はOpen-Meteoのデータです。
・PC情報：CPU、メモリ、GPU、GPUメモリ（1×1）と60秒グラフ付き（2×2）。表示している間だけ測定します。
・マウスホイール：縦型（1×1・1×2）と円形（2×2）。感度、倍率、向き、修飾キー、タップで中クリックを設定できます。
・タッチパッド：横長（3×2）と縦長（2×3）。移動、タップでクリック、2本指タップで右クリック、2本指スクロール、タップ後のドラッグ。
・スマートフォンの三本線メニューの「操作の手応え」で、Androidの振動とiPhoneのクリック音をオン／オフできます。
・管理者として実行中のウィンドウ（タスクマネージャーなど）が前面にあると、Windowsの制限でマウス操作が届きません。その場合はスマートフォンに注意を表示します。
・フェーダーは1×1、2×2、3×1、4×1、3×2、4×2から選べます。右クリックでそのページだけ移動・形の変更・非表示ができ、「このページに表示」で戻せます。右クリックの「すべてのページから削除」でその向きの全ページから消し、ショートカット一覧の「すべてのページに表示」で戻せます。

見た目とプリセット（3.1）
------------------------
・アイコンパック：PC設定画面の「アイコンパック」で .tpicons／.zip や画像のフォルダを読み込むと、アイコン選択画面にパックのタブが出ます。今のボタンのアイコンを .tpicons に書き出すこともできます。
・パックで一括変更：標準アイコンを使っているボタンを、パックの同じ種類の絵にまとめて変えます。「標準アイコンに戻す」と「元に戻す」もあります。
・ページの削除：プレビューの「ページを削除」で表示中のページを消し、後ろのページを前に詰めます。直後なら「削除を元に戻す」で戻せます。
・背景：色（13色）、グラデーション（6種）、好きな色、画像を選べます。画像はプレビューをドラッグして位置を、ホイールや「拡大」で大きさを、縦向き・横向き別に調整できます。暗くする・ぼかすも設定できます。
・画面の保存：今の画面（ボタンとその動作・配置・ページ・枠数・フェーダー・アイコン・背景）を名前を付けて20個まで保存し、「この画面に戻す」でまるごと戻せます。戻した直後なら「戻す前の画面にする」で元に戻せます。一括変更やプリセットの前にも保存するか確認します。
・自動バックアップ：設定を変えると、変える前の設定を自動で残します（2分に1回まで・最新30件）。「画面の保存」の「自動バックアップから戻す」で、その時点の画面に戻せます。
・用途別プリセット：配信者、ゲーム、在宅ワーク・会議、動画・画像編集、音楽・動画鑑賞、プログラミング。プレビューに表示中の1ページを、縦横それぞれに合わせた枠数・フェーダー・時計や天気などと一緒に置き換えます。そのページにあったボタンは消え、直後なら「プリセットを元に戻す」で戻せます。
・ボタン名が長くて枠に収まらないときは、文字を自動で小さくします。
・配信者プリセットのシーン・配信・録画ボタンは Ctrl + Shift + F1〜F6 を送ります。OBS などの配信ソフトのホットキーに同じキーを登録してください。

変更履歴
--------

1.00
・初回正式リリース。
・iPhone／Androidのブラウザから、アプリ起動、Windowsショートカット、スピーカー／マイクの音量とミュートを操作。
・QR接続、可変グリッド、縦横表示、アイコン登録、タスクトレイ常駐に対応。

1.01
・Discordのサウンドボードを開く操作を追加。
・URLを開くボタンと、定型文をWindowsのクリップボードへコピーするボタンを追加。
・設定保存後にスマートフォン画面へ移動するよう改善。

1.02
・指定したスピーカー／ヘッドセットとマイクへ直接切り替えるボタンを追加。
・ヘッドセット、イヤホン、USBマイクなどのアイコンと背景色を追加。
・背景色を選んだあともアイコン選択を続けられるよう修正。
・スピーカー／マイクフェーダーをショートカット一覧の先頭へ移動。

1.03
・ボタンの自由配置と、縦向き／横向き別の位置保存を追加。
・1マス／4マス表示、文字サイズ、アイコンサイズ、文字非表示を追加。
・ショートカットキーをボタンごとに変更できる詳細設定を追加。
・iPhoneのホーム画面など別の保存領域から開いた端末を、6桁番号でPCから承認できる機能を追加。
・インストール先のREADMEへ、1.00からの変更履歴を追加。
・アイコンの詳細設定を表示中は、操作列を画面内に固定していつでも保存できるよう改善。
・スピーカー／マイクフェーダーを右クリックして、1マス／4マス表示を切り替えられるよう追加。
・自由配置対応後に右のショートカット一覧からドラッグ追加できなくなった問題を修正。
・横向き用と縦向き用のボタンを別々に登録・編集できるよう変更。既存設定は初回に両方へ引き継ぎ。
・1マスのボタンを4マスへ変更したとき、現在位置に収まらなければ同じ向きの空き枠へ自動移動するよう改善。
・スピーカー／マイクフェーダーの位置と大きさを、横向き用と縦向き用へ分離。

1.04
・スピーカー／マイクフェーダーを、スワイプ中も約80ミリ秒間隔でPCへ反映するよう改善。
・フェーダーの位置をバー全体の絶対位置から計算し、低い音量で0%に張り付く問題を修正。
・スピーカーとマイクの音量状態を個別に更新し、一方の操作で他方が0%になる問題を修正。
・古いiPhoneのSafari向けに、タッチ操作の互換処理を追加。
・更新時に既存のTaPoard-Setup.exeが読み取り専用または一時的に使用中でも、解除と再試行を行うようインストーラーを修正。
・ボタンごとに文字背景の濃さを0～100%で設定できる機能を追加。
・操作結果のメッセージを成功時2秒、エラー時5秒で自動的に消すよう改善。
・横向きと縦向きの枠数を個別に保存できるよう変更。
・4マスのボタンやフェーダーがある状態で枠数を変更すると、収まらないボタンを空き枠または次ページへ自動移動するよう修正。

1.05
・画面や操作方法を維持したまま、内部のプログラム構成を整理。
・1.04の設定ファイル、接続キー、登録ボタンをそのまま引き継ぎ。

2.0
・時計、天気（現在／3日間）、PC情報（CPU、メモリ、GPU、GPUメモリ）の部品を追加。
・縦型マウスホイール（1×1・1×2）、円形マウスホイール、タッチパッドを追加。
・アイコンから追加する画面で、URLの直接入力とブラウザからのURLのドロップに対応。
・ホイールとタッチパッドの操作時に、Androidの振動とiPhoneのクリック音を選べるよう追加。
・横向きフェーダーと−／＋ボタン、3×1・4×1・3×2・4×2のフェーダーを追加。
・フェーダーの位置、形、表示をページごとに設定できるよう変更。
・部品を長方形（1×2、3×2など）で配置できるよう変更し、枠数を横・縦それぞれ2～8枠に統一。
・設定を settings-v2.json へ分離。1.05の設定は初回に引き継ぎ、旧ファイルはそのまま残す。
・画面に表示している情報だけをPCで取得し、表示がなくなると取得を止めるよう変更。
・管理者権限のウィンドウが前面にあるとき、マウス操作が届かないことをスマートフォンに表示。

3.1
・アイコンパック（.tpicons）の読み込みと書き出し、パックによるアイコンの一括変更を追加。
・ページの削除と、直後の「元に戻す」を追加。
・操作画面の背景色・グラデーション・背景画像（位置・拡大・暗さ・ぼかし、縦横別）を追加。
・画面（配置・動作・アイコン・背景）を名前を付けて保存・復元する機能を追加（20個まで）。
・設定の自動バックアップと、PC設定画面からの復元を追加。
・用途別プリセット6種（表示中の1ページを枠数・フェーダー・ウィジェットごと置き換え）と、好きなキーを送る「好きなキー」ボタンを追加。
・スピーカー／マイクのフェーダーをすべてのページから削除できるようにしました。
・長いボタン名を自動で縮小して枠に収めるようにしました。
