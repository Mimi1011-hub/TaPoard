# TaPoard

Windows PCを、同じルーターにつながるAndroidのChromeまたはiPhoneのSafariから操作する軽量トレイアプリです。スマートフォンへのアプリ追加やTailscaleは不要です。PCは有線LANでも使えます。

## 起動と初回設定

1. `dist\TaPoard.exe` を起動します。設定画面がブラウザで開き、通知領域に常駐します。
2. 初回だけ管理者のPowerShellで次を実行してください。

```powershell
& '<TaPoardのフォルダ>\setup-lan.ps1'
```

これはTaPoardのTCP 18781とmDNSのUDP 5353への受信を、選択されたLANアダプター・同一サブネット・このexeに限定して許可します。ネットワーク全体の種別やファイアウォール自体は変更しません。

3. AndroidまたはiPhoneを同じルーターの通常のWi-Fiに接続します。ゲストWi-Fiや端末間通信を禁止したWi-Fiでは接続できない場合があります。
4. まず左の「新しいスマートフォン用」QRコードを読み取ります。`.local` が開けない場合は、右の「左のQRが使えない場合」を使います。左はIP変更に強い `.local` 名、右は名前解決に依存しない現在のIPアドレスを使います。どちらもiPhone・Android共通です。
5. AndroidではChromeのメニューから「ホーム画面に追加」を選ぶと、TaPoardアイコンから全画面に近い表示で起動できます。
6. 必要ならChromeまたはSafariのブックマークや「ホーム画面に追加」を使ってください。

## IPアドレスが変わる場合

`dist\network.json` に保存した固有の名前（例：`tapoard-xxxxxxxxxx.local`）をmDNSで案内します。URLにはIPアドレスを使わないため、DHCPでPCのIPが変わってもブックマークを変える必要はありません。旧StreamDeck URLは移行用の別名として引き続き応答します。

Windowsのネットワーク変更通知を受けて、現在のIPv4アドレスとサブネットを再取得し、名前解決の情報を更新します。常時ネットワークをスキャンする処理はありません。切断中は操作画面を黒くして再接続を試みます。DNSキャッシュの都合で、IP変更直後の復旧には少し時間がかかる場合があります。

名前解決を遮断するWi-Fiでは、PC設定画面の現在のIPのURLを使えます。確実にIPのURLを固定したい場合は、ルーターのDHCP予約も選択肢です。現在のIPの一覧は設定画面を開き直すと更新されます。

初回に選択したLANアダプターだけを使用します。有線からWi-Fiなど別のアダプターへ変更する場合は、`network.json` の `interfaceId` とファイアウォール規則の更新が必要です。`network.json` を保存しておくと、再起動や再ビルド後も接続名を維持できます。

## 操作と設定

- スピーカー：左端の枠内を上下へスワイプしてWindowsの出力音量を0～100%で設定します。スピーカーアイコンを押すとミュートを切り替えます。
- マイク：スピーカーの横にある枠内を上下へスワイプしてWindowsの既定マイク入力音量を設定します。マイクアイコンを押すとマイクミュートを切り替えます。
- アプリ登録：PCの設定画面にあるiPhoneプレビューの「＋」または空き枠を押し、開いた小さなウィンドウへデスクトップのショートカット（.lnk）や実行ファイル（.exe）をドロップします。複数まとめて追加でき、「ファイルを選んで追加」も使えます。同じウィンドウの「URLを入力して追加」でURLと表示名（空欄ならサイト名）を入力するか、ブラウザのURLをドロップすると、そのページを開くボタンになります。登録後は自動保存されます。
- Windowsが持つアプリアイコンを登録時にPNGとして取り出し、iPhoneのボタンへ表示します。アイコンが取得できないアプリは、名前の先頭文字を代わりに表示します。
- iPhone側ではアイコンをボタン枠の約80%まで拡大し、ボタン名を下端へ重ねて表示します。
- 操作画面は初期状態で横5枠×縦3枠です。右上の三本線メニューから横・縦それぞれ2～8枠へ変更でき、PCプレビューとiPhoneへ共有されます。iPhoneを縦向きにした場合は5×3を3×5のように自動で並べ替え、横にはみ出さないようにします。先頭2枠はスピーカーとマイクで、残りをアプリに使い、収まらない分は自動的にページ分けします。
- PC設定画面の「▲ 前へ」「▼ 後ろへ」でアプリボタンの並び順を変更できます。追加・並べ替え・削除は自動保存されます。表示名やパスを手で修正した場合だけ「設定を保存」を押してください。
- PC設定画面のiPhoneプレビューでは、登録済みボタンを右クリックすると専用メニューが開き、削除、前後への移動、詳細設定への移動ができます。
- 登録済みボタンの右クリックメニューまたは詳細設定の「アイコンを選ぶ」から、基本、音楽・音声、通信、PC、制作、方向の92種類のアイコンを選べます。「自動取得」でアプリ本来のアイコンまたはショートカット分類アイコンへ戻せます。
- アイコン選択画面ではPNG・JPEG・WebPのオリジナル画像も選べます。ブラウザ側でアイコン向けサイズへ縮小して保存するため、スマートフォンへ送るデータ量を抑えます。
- スピーカーとマイクのフェーダーは、右側の「スピーカー・マイク」一覧からiPhoneプレビューの希望する枠へドラッグして移動できます。位置と1マス／4マス表示は横向き・縦向きで別々に保存されます。フェーダーを右クリックして上下左右へ移動することもできます。もう一方のフェーダーが移動先にある場合は位置を交換します。各フェーダーは1個だけで、削除されないため、音量操作が完全になくなることはありません。
- PC設定画面の上部には、iPhoneで現在表示しているページと接続状態を表示します。PC側の「前のページ」「次のページ」で切り替えると、接続中のiPhoneにも反映されます。iPhone側で切り替えた場合もPCのプレビューが更新されます。
- PC設定画面のiPhoneプレビューは「横」「縦」で編集する向きを切り替えられます。登録ボタン、ショートカット、位置、大きさ、文字、アイコン、キー設定は向きごとに独立して保存されます。既存設定は初回だけ両方へ複製されます。iPhone本体は端末の向きに合う設定へ自動的に切り替わります。
- 1マスのボタンを4マスへ変更したときに現在位置からはみ出す場合は、選択中の向きにある空き2×2領域へ自動移動します。
- 右側のショートカット一覧から、スピーカー・マイク、よく使う操作、Discord、Windows、音楽・メディア、ブラウザ、CLIP STUDIO PAINTの操作を追加できます。Discordにはゲームオーバーレイのサウンドボードを開くボタンもあります。項目をiPhoneプレビューの希望する枠へドラッグ＆ドロップすると、その位置へ追加して自動保存します。「追加」ボタンでも現在のページへ追加できます。ショートカットは許可済みの組み合わせだけを送信します。
- 「URL・テキスト」からURLボタンを追加すると、iPhoneまたはAndroidで押したときにPCの既定ブラウザでHTTP・HTTPSのページを開きます。ローカルファイルやスクリプト形式のURLは登録できません。
- コピー用テキストには定型文、メールアドレス、コマンドなどを32768文字まで保存できます。スマートフォンでボタンを1回押すとWindowsのクリップボードへコピーされ、PC側ですぐ貼り付けられます。内容はスマートフォンへ送らず、PCの設定ファイルだけに保存します。
- スピーカー・マイクには各ミュートと5%単位の音量上げ下げがあります。よく使う操作にはコピー、貼り付け、切り取り、取り消し、やり直し、保存、すべて選択、検索、ファイルを開く、新規作成があります。
- CLIP STUDIO PAINTには51操作を用意しています。保存・編集に加えて、選択範囲、レイヤー作成・結合・クリッピング、キャンバス切替、ルーラーとスナップ、手のひら・スポイト・自動選択・テキストなどの主要ツールを登録できます。CLIP STUDIO側でキー設定を変更している場合は、その設定に合わせて動作が変わります。
- 音楽・メディアには「再生／一時停止」「前の曲」「次の曲」「停止」があり、Windowsのメディアキーに対応するSpotify、YouTube、音楽プレイヤーなどへ送信されます。
- ブラウザのショートカットは、その時点でPC上の操作対象になっているブラウザへ送られます。Discord操作はDiscordデスクトップ版へ送る直前だけDiscordを一時的に操作対象にし、送信後は元のアプリへ戻します。最小化中だったDiscordは操作後にもう一度最小化します。
- Windows欄には画面切り取りに加えてPrint Screen、アプリ切替、最大化・最小化、左右への整列、クイックリンク、画面ロック、ファイル名を指定して実行、タスクマネージャー、ウィンドウを閉じる、絵文字、クイック設定、画面出力切替があります。
- ショートカットは元のファイルから起動するため、そこに設定された起動先・引数・作業フォルダーが保たれます。登録後に元のショートカットを削除・移動すると起動できなくなるので、再登録してください。
- 手入力での登録も引き続き使えます。管理者権限が必要なアプリは対象外です。
- QRコードには48文字・192ビットの暗号学的ランダム接続キーを含めます。キーはURLのフラグメントへ入れ、ブラウザへ保存した直後にアドレス欄から消すため、HTTPリクエストやアクセス履歴には送信されません。QRを使えない場合はPC画面から長いキーをコピーして手入力できます。以前の12文字キーで接続済みのiPhoneも互換用としてそのまま使えます。接続キーを再発行すると、新旧両方のキーを無効にします。
- 設定：トレイアイコンの右クリックからブラウザを開きます。登録・キー再発行APIはこのPCからだけ使えます。
- 終了：トレイアイコンの右クリック → 終了。

2.0の設定とキーは `dist\data\settings-v2.json` に保存されます。このファイルを共有しないでください。初回だけ旧 `settings.json` から移行し、旧ファイルは変更せず残します。自宅LAN内のHTTP通信であり、通信内容自体はTLSで暗号化しません。外部公開やルーターのポート転送は不要です。先に設定した旧アプリ向けTailscale Serveは停止しています。

## 2.0の部品

- 右側のショートカット一覧の「時計・情報表示」「マウス操作」から部品を追加できます。ボタンと部品は1×2や3×2などの長方形で配置できます。
- 時計：デジタルとアナログ（2×2）。スマートフォン側の時刻で動き、PCへの追加通信はありません。
- 天気：現在の天気（1×1）と3日間の天気（2×2）。PC設定画面で地域を検索して選びます。予報はOpen-Meteoから取得してPCでキャッシュします。
- PC情報：CPU、メモリ、GPU、GPUメモリ（1×1）と60秒グラフ付きのPC情報（2×2）。画面に表示している間だけPCで測定し、表示がなくなると測定を止めます。
- マウスホイール：縦型（1×1・1×2）と円形（2×2）。感度、倍率、向き、Ctrl・Shift・Altとの組み合わせ、タップで中クリックを設定できます。
- タッチパッド：横長（3×2）と縦長（2×3）。移動、タップでクリック、2本指タップで右クリック、2本指スクロール、タップ後のドラッグに対応し、長押しの動作を選べます。複数の端末が同時に操作した場合は先に触れた端末が優先され、他の端末には「他端末が操作中」と表示します。
- 操作の手応え：スマートフォンの三本線メニューで、Androidは振動、iPhoneはクリック音をこの端末だけオン／オフできます。iPhoneは消音モード中は鳴りません。
- タスクマネージャーなど管理者として実行中のウィンドウが前面にあると、Windowsの制限でマウス操作が届きません。その場合はスマートフォンに注意を表示します。
- スピーカー・マイクのフェーダーは1×1、2×2のほか、横向きの3×1、4×1、3×2、4×2を選べます。横向きには−／＋ボタンがあります。フェーダーを右クリックすると、そのページだけ移動・形の変更・非表示ができ、非表示にしたフェーダーはショートカット一覧の「このページに表示」で戻せます。

## 負荷とiPhoneの画面

C#とWindows標準の.NET Framework 4.xを使用し、Electronや追加ランタイムは不要です。常駐アプリの実測メモリは約41MB、待機5秒間のCPU使用時間は0秒でした。これは短時間・このPCでの値で、使用状況で変化します。

PCとiPhoneの画面同期は、状態が変化するまで通信を待機する方式です。短い間隔で連続確認しないため、待機中のCPU負荷を抑えています。ブラウザがバックグラウンドの間は同期を停止します。mDNSは問い合わせとネットワーク変更に応じて動きます。

画面維持は初期状態でオンです。新しい端末では標準の画面維持APIを使い、iPhone 8などHTTP接続で標準APIを使えない端末では同梱したNoSleep.jsの動画方式へ切り替えます。PCとの切断確認後は画面維持を解除して黒い画面に切り替え、iPhoneの自動ロックに任せます（通常最大約14秒で切断検出）。NoSleep.jsはMITライセンスで、ライセンス本文を `dist\web\NoSleep.LICENSE.txt` に同梱しています。QRコードはKazuhiko Arase氏のMITライセンス版qrcode-generatorでPC内だけで生成し、キーを外部サービスへ送信しません。ライセンス本文は `dist\web\QRCode.LICENSE.txt` に同梱しています。

## ビルドと確認

```powershell
.\build.ps1
.\test.ps1
.\package.ps1
node tests/mdns-check.js <PCの現在のLANのIPv4アドレス>
```

ビルドにはWindows標準のC#コンパイラーを使い、外部パッケージのダウンロードはしません。Node.jsは開発用mDNSテストでのみ使用します。実行中のexeを更新する前にトレイから終了してください。配布時は `dist` のexeとwebフォルダーを一緒に保管してください。

`package.ps1` は `release\TaPoard-Setup-2.0.exe` とSHA256ファイルを作成します。ブラウザと `VERSION.txt` には `2.0` が表示され、`VERSION.txt` には元のコミット番号も記録します。未コミット変更を含む場合は `2.0+コミット番号.dirty` と表示されるため、その配布物は配らないでください。インストーラーにはアプリ、Web画面、ファイアウォール設定、アンインストール機能が含まれます。デスクトップショートカット、スタートメニュー登録、Windowsログイン時の自動起動はインストール画面で個別に選べます。自動起動は初期状態でオフで、有効時はブラウザを開かず通知領域へ起動します。現在の接続キー、登録アプリ、ネットワーク設定、ログは含めません。インストール先はユーザーごとの `%LOCALAPPDATA%\TaPoard` です。コード署名証明書を使用していないため、別のPCではWindowsが発行元未確認の警告を表示する場合があります。

セットアップ中に別の場所のTaPoardが起動している場合は、二重起動で初期設定が止まらないようインストーラーが終了させてからインストール版を起動します。LAN設定の失敗は、管理者確認のキャンセル、アプリ起動失敗、設定スクリプト失敗を区別して表示し、診断内容を `%TEMP%\TaPoard-install.log` に記録します。

## ソース構成

- `src\Program.cs`：起動、設定ファイルの読み込みと移行、通知領域アイコン、共有状態
- `src\Program.Http.cs`：HTTPの受信・応答、静的ファイル配信、認証判定
- `src\Program.Api.cs`：`/api/*` の各エンドポイント（状態同期、レイアウト、音量、設定保存、操作実行、ペアリング）
- `src\Settings.cs`：`settings-v2.json` に保存する設定とボタンの形式
- `src\SettingsFile.cs`：旧設定からの一度限りの移行と、v2設定の安全な保存
- `src\WidgetRegistry.cs`：部品種類・許可サイズ・種類別設定・スマートフォンへの公開項目
- `src\DeckLayoutV2.cs`：縦横それぞれの長方形配置・フェーダー位置・枠数制約の検証と再配置
- `src\SecureKeys.cs`：接続キーの乱数生成
- `web\app.js` / `web\style.css`：スマートフォンとPC設定画面の共通Web画面

TaPoard専用アイコンは `assets\TaPoard-icon.png` を原本として、Windows実行ファイル用の複数解像度ICOと、ブラウザ・Android・iPhoneホーム画面用PNGへ変換して組み込んでいます。

検証済み：ビルド、認証とアクセス制限、exe・ショートカットからのPNGアイコン抽出、更新がない場合のアイコン再送抑制、DNSパケットとサブネット判定の単体テスト、実際のマルチキャスト問い合わせに対する現在IPの応答。実際のDHCP変更を伴う復旧は未確認です。

Windowsサインイン時に起動したい場合は `Win+R` → `shell:startup` にexeのショートカットを置き、リンク先の末尾に ` --silent` を追加してください。

mDNSの仕組み：[Apple Bonjour](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/NetServices/Articles/domainnames.html)、[RFC 6762](https://www.rfc-editor.org/info/rfc6762/)。

音声機器の切り替え（1.02）
--------------------------
PCの右側「スピーカー・マイク」にある「出力先を切替」「入力先を切替」を追加、または空き枠へドラッグします。詳細設定の一覧で機器を選び、表示名を確認して「設定を保存」を押します。スマートフォンでボタンを押すと、その機器へ直接切り替わります。
Windowsの通常用・通話用の既定デバイスを切り替えます。Discordやゲームで機器を個別指定している場合、その指定は変わりません。未接続の機器は使用できません。ドライバー更新等で機器IDが変わった場合は一覧から選び直してください。Windowsの非公開インターフェイスを使用するため、Windows更新によって動作しなくなる可能性があります。
アイコンにはヘッドセット・イヤホン・USBマイクなど16種類を追加しました。「アイコンを選ぶ」でプリセットと背景色（標準＋9色）を選べます。背景色はアプリから取得した画像・オリジナル画像には適用されません。
