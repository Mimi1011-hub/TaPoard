ICON PACKS

アイコンパック

アイコン一式をまとめたファイル（.tpicons・.zip・Stream Deck の .streamDeckIconPack）や画像（PNG・JPEG・WebP・SVG）を読み込むと、アイコン選択画面にパックごとのタブが出ます。読み込んだ画像は縮小してこのPCに保存します。

パックで一括変更

標準アイコンを使っているボタンを、パックの中の同じ種類の絵にまとめて変えます。アプリから取り込んだアイコンとオリジナル画像は変えません。

パックの作り方

画像（PNG・JPEG・WebP）と icons.json を zip にまとめ、拡張子を .tpicons にします。icons.json がなくても、画像のファイル名がアイコン名になります。

{
  "format": "tapoard-icons", "version": 1,
  "name": "パックの名前", "author": "作った人",
  "icons": [
    { "file": "icons/mic.png", "name": "マイク", "key": "microphone" }
  ]
}

key に標準アイコンの名前（microphone、speaker など）を書くと、あとで「パックで一括変更」したときにそのボタンの絵が置き換わります。

アイコンの詳細設定

上の「横／縦」で選択中の向きに登録されたボタンだけを表示します。名前、位置、アイコンなどを調整し、変更後は「設定を保存」を押してください。

この PC の状態を確認しています…

  1. ネットワークを「プライベート」にするWindows の「設定」→「ネットワークとインターネット」→ 使っている「Wi-Fi」または「イーサネット」→ つながっているネットワークを開き、「ネットワーク プロファイルの種類」を「プライベート ネットワーク」にします。自宅のルーターにだけ設定してください。駅やお店の Wi-Fi は「パブリック」のままにします。
  2. TaPoard の通信を許可し直す下の「はい」を押すと、TaPoard だけがこのルーターの中から受け付けるよう、ファイアウォールの許可を追加し直します。Windows の管理者の確認が出たら「はい」を選んでください。以前に Windows の確認画面で「キャンセル」を押してできた、TaPoard を止める設定も取り除きます。
  3. スマートフォンをもう一度つなぐスマートフォンが PC と同じルーターの Wi-Fi につながっていることを確かめ、QR コードを読み取り直します。ゲスト用 Wi-Fi や端末どうしの通信を禁止した Wi-Fi ではつながりません。
